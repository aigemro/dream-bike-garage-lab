# 프로필 화면 디자인 검토

> 기준일: 2026-08-15
> 관련 트랙: `ART & AUDIO > 홈 화면 디자인 A안`(#130), `ART & AUDIO > 자전거 수집 화면 디자인`(#147), `META PROGRESSION > 직급·커리어 성장`(#107)

## 1. 검토 목적

홈 화면 디자인 A안(따뜻한 생활형 픽셀 Garage)의 하단 **프로필 탭(프로필 Lv.12)** 에서 진입하는 프로필 화면을 어떤 정보 구조로 보여줄지 검토합니다. 자전거 수집 화면 디자인 트랙과 동일한 방식으로, 홈 A안의 시각 언어와 데이터를 고정한 뒤 **화면 형태만 바꾼 복수 안**을 만들어 비교합니다.

이 문서는 승진 조건·보상 수치 같은 게임 규칙을 결정하지 않습니다. 직급 규칙 비교는 `META PROGRESSION > 직급·커리어 성장` 트랙 담당이며, 여기서는 이미 있는 데이터를 **어떻게 보여줄지**만 다룹니다.

## 2. 프로필 화면에 담을 정보 검토

요청 기준은 "사용자 정보 + 그동안의 작업 통계 + 직급"입니다. 후보 정보를 다음과 같이 정리했습니다.

| 정보 | 판단 | 근거 |
|---|---|---|
| 닉네임·정비사 캐릭터·레벨 | 채택 | 프로필의 최소 단위. 홈 A안 프로필 탭의 Lv.12와 연결 |
| Garage 이름·플레이 일차 | 채택 | 생활감·애착 표현. MY LITTLE GARAGE 문구 재사용 |
| 현재 직급과 직급 사다리 | 채택 | 견습 알바→샵 오너 성장 축. 직급·커리어 트랙과 데이터 일치 |
| 다음 승진 조건 진행도 | 채택 | 프로필에서 다음 행동(주문 플레이)으로 연결하는 고리 |
| 작업 통계 6종 | 채택 | 납품·조립·머지·누적 급여·연속 출근·수집. MVP 루프에서 실제 쌓이는 값만 사용 |
| 주간 작업 기록 그래프 | 조건부 채택 | C안에서만 검증. 저장 데이터 범위 확정 전이므로 화면 표현만 확인 |
| 랭킹·친구 비교 | 보류 | 소셜 기능 범위 미정. 홈 A안 RANK 메뉴와 중복 |
| 업적·배지 목록 | 보류 | 업적 콘텐츠 미설계. 통계와 역할이 겹침 |
| 설정·계정 연동 | 제외 | 플랫폼(앱인토스) 트랙 담당. 프로필의 감성 검증과 무관 |

## 3. 공통 고정 데이터

홈 A안·수집 화면 디자인 트랙과 같은 세계관 데이터를 사용합니다. 세 방안 모두 동일하게 고정합니다.

| 항목 | 값 |
|---|---|
| 닉네임 / 레벨 | 정비사 두리 / Lv.12 (다음 레벨까지 60%) |
| 직급 사다리 | 견습 알바 → 견습 정비사 → 정비사 → 시니어 정비사 → 마스터 정비사 → 샵 오너 |
| 현재 직급 | 견습 정비사 (2/6단계) |
| 다음 승진 조건 | 정비사: Lv.15 도달 + 납품 40건 (현재 Lv.12, 34건) |
| 작업 통계 | 납품 34건 · 완성차 조립 12대 · 머지 512회 · 누적 급여 18,500 · 연속 출근 6일 · 수집 8/24 |
| 재화 | 에너지 72/100 · 코인 2,480 |

## 4. 비교 방안 정의

프로필 화면의 주인공을 무엇으로 두는지에 따라 세 방안으로 나눕니다.

| 방안 | 주인공 | 화면 구성 | 검증 질문 |
|---|---|---|---|
| A안 정비사 사원증 카드 | 나 (정체성) | 사원증 카드(캐릭터·닉네임·직급 스탬프) + 통계 요약 + 승진 진행 한 줄 | 캐릭터와 정체성 중심 구성이 Garage 애착을 가장 높이는가? |
| B안 커리어 승진 보드 | 직급 (성장 경로) | 6단계 직급 사다리 + 다음 승진 조건 진행 바 + 단계별 해금 안내 | 승진 로드맵 중심이 장기 목표를 가장 선명하게 만드는가? |
| C안 작업 기록 대시보드 | 기록 (통계) | 통계 6타일 + 주간 기록 픽셀 그래프 + 상단 유저·직급 요약 | 쌓인 숫자 중심 구성이 반복 플레이 성취를 가장 잘 보여주는가? |

세 방안 모두 390×810, 홈 A안 팔레트, `← HOME` ↔ 홈 축약 프리뷰(프로필 탭 강조) 전환 흐름을 공유합니다.

## 5. 평가 기준

- 진입 3초 안에 '내 프로필·성장 화면'임이 읽히는가
- 사용자 정보·작업 통계·직급 3요소가 390 폭에서 모두 읽히는가
- 승진 조건 진행이 다음 주문 플레이 동기로 이어지는가
- 홈 A안과의 시각 연속성(팔레트·프레임·타이포)이 유지되는가
- 반복 방문할 가치(변하는 숫자·다음 목표)가 느껴지는가

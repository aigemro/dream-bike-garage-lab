# 최종 디자인·오디오 MVP 수직 슬라이스

관련 이슈: [#192 MVP 릴리스 수직 슬라이스 통합](https://github.com/aigemro/dream-bike-garage-lab/issues/192) · 상위 트랙: [#113 출시 MVP 통합 검증](https://github.com/aigemro/dream-bike-garage-lab/issues/113)

## 목적

화면 디자인 트랙과 Art & Audio 트랙에서 검증한 결과를 다시 그리지 않고 하나의 실행 흐름으로 연결해, 메인 프로젝트로 옮기기 전 릴리스 통합 상태를 확인합니다.

## 통합 선택안

- 타이틀·로딩: 공방 간판 A안
- Garage 홈: 따뜻한 생활형 픽셀 A안
- 첫 플레이 안내: 정비사 말풍선 A안
- 게임 화면: 모바일 세로 B안의 주문·택배·6×7 보드·자동 장착
- 납품·보상: 급여 봉투 A안
- 자전거 수집: A안 도감, B안 Garage 전시, C안 드림 바이크 성장을 모두 포함
- 프로필: 정비사 사원증 A안
- 설정: 공방 관리 서랍 A안
- 아트: 홈 A안의 캐릭터·종이/목재 UI·공용 픽셀 자전거와 부품
- 오디오: HOME/WORK/REWARD BGM 변주와 탭·택배·머지·장착·완료·보상·오류 효과음

## 상태 연결

- 코인, 완료 주문 수, 다음 주문, 튜토리얼 완료 여부, BGM·효과음·진동 설정을 하나의 로컬 저장 계약으로 관리합니다.
- 납품 후 급여 봉투를 열면 코인이 실제 상태에 반영됩니다.
- 드림 바이크 성장에서 사용한 코인은 홈과 통합 헤더에 함께 반영됩니다.
- 새로고침 후에도 통합 진행 상태가 복구됩니다.

## 자전거 수집 동선

- 홈 하단 `자전거 8/24`에서 수집 A 도감으로 진입합니다.
- 수집 A에서 자전거를 선택하고 `상세·성장 보기`를 누르면 해당 자전거를 선택한 수집 C로 이동합니다.
- 홈 우측 `전시 보기` 또는 수집 화면 하단 `B · 전시` 탭에서 수집 B Garage 전시로 이동합니다.
- 수집 A/B/C 하단 탭으로 세 화면을 오갈 수 있으며, HOME으로 동일한 Garage 홈에 복귀합니다.
- 모든 화면은 390×810 논리 해상도를 유지하고 Lab 브라우저에서는 가용 높이에 맞춰 축소되어 별도 스크롤 없이 표시됩니다.

## 검증 순서

1. 타이틀 로딩 완료 후 TAP TO START
2. 홈 PLAY에서 첫 플레이 안내 확인
3. 택배 주문·개봉·보드 배치·2-to-1 머지
4. 목표 부품 자동 장착과 주문 완료
5. 급여 봉투 개봉 후 홈 또는 다음 주문 전환
6. 홈 자전거 → 수집 A → 상세·성장 C, 홈 전시 보기 → 수집 B 진입·복귀
7. BGM 공간 전환과 핵심 효과음 확인
8. 새로고침 후 코인·주문·설정 복구 확인

## 경계

이 구현은 Lab의 릴리스 수직 슬라이스 검증용입니다. 실제 앱인토스 SDK, 서버 계정, 광고·결제, 실제 브랜드와 최종 밸런스는 포함하지 않습니다. 검증 후 선택안과 상태 계약을 메인 프로젝트로 옮깁니다.

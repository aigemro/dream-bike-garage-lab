# 쿨다운·충전식 생성기형 부품 수급

## 구현 방식
충전량을 가진 생성기를 탭해 부품을 뽑고, 충전량이 소진되면 쿨다운 후 다시 충전됩니다. 머지 장르에서 표준으로 쓰이는 생성기 방식입니다.

## 확인할 점
- 장르 표준 생성기가 주문 단위의 짧은 세션 구조와 잘 맞는지 확인합니다.
- 충전 대기가 자연스러운 휴식이 되는지, 진행 차단으로 느껴지는지 관찰합니다.
- 충전량·쿨다운 수치가 밸런스 변수로 관리 가능한지 확인합니다.

## 비교 조건
같은 보드 크기·부품 구성·주문 목표에서 A안(즉시 생성 버튼형)을 기준선으로 세션 길이·대기 체감·전략성을 비교합니다.

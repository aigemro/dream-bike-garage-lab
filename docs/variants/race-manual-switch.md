# D안 · 버튼 선택형 레이스 중계 전환

## 검증 가설

자동 레이스를 관람하는 동안 플레이어가 보고 싶은 시점을 직접 고르게 하면, 평소에는 내 자전거의 주행에 몰입하고 순위가 궁금할 때만 전체 중계를 확인할 수 있다. 전환 버튼이 단순하고 레이스 상태가 끊기지 않으면 자동 전환보다 개인별 관람 취향을 잘 수용한다.

## 이번 구현

- C안과 동일한 `리버사이드 3K 챌린지` 3,000m와 참가·시뮬레이션·보상 조건 사용
- 레이스는 A안의 내 자전거 사이드뷰로 시작
- 하단에 `전체 중계 보기` 버튼을 배치해 원하는 시점에 B안 8레인 전광판으로 전환
- 전광판에서는 버튼이 `내 자전거 보기`로 바뀌며, 사이드뷰로 다시 돌아갈 수 있음
- 한 레이스 안에서 횟수 제한 없이 양방향 전환 가능
- 전환 시 현재 타임라인을 그대로 사용해 거리·경과 기록·실시간 순위·배속·최종 결과 유지
- 짧은 플래시와 전환 배너로 화면 변경을 중계 카메라 전환처럼 전달

## 체험 순서

1. 성장 프리셋을 고르고 3,000m 레이스에 출전한다.
2. 사이드뷰 주행 중 `전체 중계 보기`를 눌러 8레인 순위판으로 바꾼다.
3. `내 자전거 보기`를 눌러 다시 사이드뷰로 돌아온다.
4. 오르막·내리막·마지막 스퍼트에서 각각 전환해 정보 가독성과 몰입 변화를 비교한다.
5. 전환 전후 거리·기록·순위와 결승 정산 결과가 이어지는지 확인한다.

## 비교 기준

- C안: 2,400m에서 자동으로 전체 중계 전환 — 연출 흐름이 일관되고 조작이 필요 없음
- D안(본 방안): 플레이어가 원하는 순간 양방향 전환 — 취향과 상황에 맞지만 버튼 조작이 추가됨

## 확인할 점

- 전환 버튼의 위치와 문구가 레이스 관람을 방해하지 않는가?
- 시점을 자주 바꿔도 현재 거리와 순위를 놓치지 않는가?
- 플레이어가 실제로 전체 중계를 필요할 때 찾아 쓰는가?
- 자동 전환 C안보다 마지막 결승의 긴장감이 약해지지는 않는가?

## 프로토타입 경계

3,000m 장거리와 양방향 무제한 전환은 Lab 비교용이다. 실제 출시안에서는 사용자 테스트 결과에 따라 전환 가능 구간, 횟수 또는 기본 시점을 조정한다.

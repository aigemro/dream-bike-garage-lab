# Prototype A: 따뜻한 픽셀 정비사 사원증

## 트랙 역할

이 방안은 직급·승진 규칙을 다시 결정하지 않습니다. 홈 화면 디자인 A안의 프로필 탭에서 진입하는 프로필 화면을 '나(정체성)' 중심의 사원증 카드로 구성해, 사용자 정보·작업 통계·직급이 한 화면에서 읽히는지와 Garage 애착을 검증합니다. 정보 구조 검토는 `docs/PROFILE_SCREEN_DESIGN_REVIEW.md`를 따릅니다.

## 디자인 방향

- 목재 프레임과 크림 종이 질감의 사원증 카드를 화면 주인공으로 둡니다.
- 카드 안에 정비사 캐릭터 초상, 닉네임, Garage 이름, 레벨·경험치, 플레이 일차를 담습니다.
- 현재 직급(견습 정비사)은 붉은 스탬프 도장으로 표현해 공방 서류의 생활감을 만듭니다.
- 카드 아래 작업 통계 6종을 작은 타일로 요약하고, 다음 승진 진행을 한 줄 바로 보여줍니다.
- 카드 배경 변경 상호작용으로 프로필을 꾸미고 싶은 동기를 확인합니다.

## 공통 조건

- 390×810 세로, 홈 A안과 동일 팔레트
- 동일 프로필 데이터: 정비사 두리 Lv.12, 견습 정비사(2/6단계), 통계 6종, 에너지 72/100·코인 2,480
- ← HOME으로 홈 A안 축약 프리뷰(프로필 탭 강조)와 전환하며 진입 흐름을 확인

## 인터랙션

카드 배경 변경 버튼 → 크림 종이·목재 프레임·민트 작업복 3종 순환 → 토스트 피드백. 통계·승진 수치는 고정 데이터이며 규칙은 이 트랙에서 결정하지 않습니다.

## 평가 기준

- 진입 3초 안에 '내 사원증·프로필'임이 읽히는가
- 카드 안에서 닉네임·직급·레벨이 한눈에 구분되는가
- 통계 요약 6종이 카드와 시각적으로 경쟁하지 않는가
- 카드 배경 변경이 꾸미고 싶은 동기를 만드는가
- 390 폭에서 카드·통계·승진 진행이 모두 읽히는가

## 함께 비교하는 방안

- B안: 따뜻한 픽셀 커리어 승진 보드 (직급 사다리 중심)
- C안: 따뜻한 픽셀 작업 기록 대시보드 (통계·그래프 중심)

세 방안은 같은 프로필 데이터와 홈 A안 진입 흐름을 사용하며, 화면의 주인공만 바꿔 비교합니다.

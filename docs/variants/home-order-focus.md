# 주문·자전거 강조형 메인 홈

## 구현 방식
현재 주문 자전거와 조립 진행률을 큰 상단 카드로 보여줍니다. 플레이어가 무엇을 만들고 있는지 먼저 인지한 뒤 아래의 머지 보드로 자연스럽게 이동하도록 구성합니다.

## 확인할 점
- 주문 목표와 완성 자전거에 대한 기대감이 A안보다 명확한지 확인합니다.
- 주문 카드가 커지면서 머지 보드 조작성이 나빠지지 않는지 관찰합니다.
- 이벤트·랭킹·Tour 진입 버튼이 보조 기능으로 충분히 발견되는지 확인합니다.

## 비교 조건
A안·C안과 같은 주문, 재화, 스태미너, 보드 데이터와 메뉴 기능을 사용하고 정보 배치 우선순위만 비교합니다.

# Prototype B: 블루아워 정비소 Garage

## 트랙 역할

이 방안은 게임 구조를 다시 결정하지 않습니다. GAME CORE > 메인 홈·플레이 화면 > E안에서 합의한 Garage 홈 정보 구조를 고정한 채 시각 언어만 비교합니다. 상단 자원·주문 카드, 좌우 보조 메뉴, 중앙 드림 바이크, 중앙 하단 수집·성장 지표, 하단 PLAY까지 배치와 데이터는 A안과 완전히 동일하며, 달라지는 것은 시간대·조명·질감뿐입니다.

## 디자인 방향

- 해질녘 도시의 자전거 정비소를 무대로 삼습니다. 창밖은 깊은 청색에서 노을빛으로 이어지는 하늘 그라데이션, 도시 실루엣, 하나둘 켜진 창문 불빛으로 블루아워의 공기를 만듭니다.
- 실내는 어두운 청회색 벽과 벽돌 줄눈 힌트, 나무 작업대, 공구 페그보드 실루엣, 어두운 콘크리트 바닥과 원근 라인으로 정비소의 밀도를 만들되 중앙 자전거보다 낮은 대비로 유지합니다.
- 중앙 드림 바이크는 정비 스탠드 위에 거치하고 위에서 내려오는 원뿔형 스포트라이트로 무대화합니다. 프레임은 선명한 레드 오렌지 계열로 어두운 배경과 강하게 대비시켜 화면의 주인공으로 세웁니다.
- UI는 반투명 다크 패널에 앰버·골드 포인트 컬러와 가는 밝은 외곽선을 더해 금속 명판 느낌으로 통일합니다. A안의 종이·나무 질감과 대비되는 방향입니다.
- PLAY 버튼은 밝은 앰버 면과 상단 하이라이트 밴드로 그라데이션 느낌을 주어 화면에서 가장 크고 눈에 띄게 만듭니다.
- 어두운 배경 위 텍스트는 밝은 크림·앰버 색의 시스템 산세리프 계열로 가독성을 확보합니다.
- 특정 게임의 고유 자산·캐릭터·타일·UI를 복제하지 않는 독자적 디자인입니다.

## 회의안 반영

- 상단 바: ENERGY 72/100 게이지와 COIN 2,480
- 상단 주문 카드: TODAY'S ORDER, 통학용 어반 바이크, 진행 2 / 4, 보상 1,000, 미니 자전거
- 좌측 버튼: EVENT 3, RANK #18
- 우측 버튼: TOUR D2, 조립 2/4, STATUS Lv.12
- 중앙: 스포트라이트를 받는 대표 드림 로드바이크와 MY LITTLE GARAGE 명판, 나의 드림 로드바이크 문구
- 중앙 하단: COLLECTION 8 / 24, NEXT GOAL TRAIL MTB, 주문 2건 남음, Garage 성장 33% 게이지
- 하단 바: 프로필 Lv.12, 가장 큰 PLAY 버튼, 자전거 8/24
- 토스트 영역: 버튼 탭 시 이벤트 준비 중 등 짧은 안내로 교체

## 인터랙션

PLAY를 누르면 축약된 주문·머지 미리보기 화면으로 이동합니다. 미리보기에는 HOME 복귀 버튼, 주문 헤더, 5x4 머지 보드 요약, 부품 주문하기 버튼이 있으며 부품 배치 데이터는 A안과 동일합니다. HOME으로 돌아오면 플레이 결과가 Garage에 쌓인다는 토스트가 표시되어 홈과 플레이의 순환 구조를 확인할 수 있습니다. 좌우 보조 메뉴는 정보 계층 검증용 피드백 버튼으로, 탭 시 토스트 문구만 갱신됩니다.

## 평가 기준

- 차분한 블루아워 정비소 무드가 Garage 소유감과 몰입을 높이면서 어두운 배경 위 정보 가독성을 유지하는가
- 3초 안에 대표 자전거와 PLAY를 찾는가
- 스포트라이트와 앰버 포인트가 시선을 중앙 자전거와 하단 PLAY로 자연스럽게 이끄는가
- 어두운 배경 위 밝은 크림·앰버 텍스트가 390x810 세로 화면에서 충분히 읽히는가
- 야간 톤이 반복 노출 시 답답하거나 지나치게 어둡게 느껴지지 않는가

## A안과의 비교 포인트

- 낮의 햇살 공방(A) 대 해질녘 작업등 정비소(B)라는 시간대와 조명 무드 차이
- 밝은 배경 위 어두운 글자(A) 대 어두운 배경 위 밝은 글자(B)의 가독성 차이
- 종이·나무 질감 UI(A) 대 반투명 다크 패널과 금속 명판 UI(B)의 인상 차이
- 배경과 비슷한 대비 속의 자전거(A) 대 스포트라이트로 무대화한 자전거(B)의 주인공 강조 방식 차이
- 정보 구조와 데이터가 동일하므로 순수하게 시각 언어의 효과만 비교

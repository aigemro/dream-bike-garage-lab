# 소프트 타이머·시간 vs 품질

## 구현 방식
주문마다 소프트 타이머가 있어 시간 안에 납품하면 시간 보너스를, 시간을 넘기더라도 더 높은 등급 부품으로 납품하면 품질 보너스를 받습니다. 실패 없이 두 보상 중 하나를 선택하게 만드는 구조로, 다른 머지 게임과의 차별화 지점 후보입니다.

## 확인할 점
- 시간과 품질 중 선택하는 긴장감이 실제 재미로 이어지는지 확인합니다.
- 소프트 타이머가 압박이 아니라 선택지로 느껴지는지 관찰합니다.
- 두 보너스의 크기 균형이 한쪽 전략으로 쏠리지 않는지 확인합니다.

## 비교 조건
같은 주문 구성·납품 횟수에서 A안(고정 급여)·B안(성과 보너스)과 보상 체감·전략 선택의 재미를 비교합니다.

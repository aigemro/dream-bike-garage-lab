# 자유 보드 + 주문 가이드 조합형

## 구현 방식
자유 보드의 생성·정리·선행 제작은 유지하고, 현재 주문에 필요한 부품과 목표 레벨을 최소한으로 안내합니다.

## 1차 구현 범위
- A/B와 동일한 6×7 보드·4종 부품·Lv.1~Lv.4 조건
- 부품 종류를 플레이어가 자유롭게 선택
- 주문 3종과 납품 루프
- 다음 목표 텍스트와 관련 셀 강조
- 시간·행동·머지·오입력·빈 칸 수 실시간 표시

## 확인할 점
A안의 공간 관리 자유도를 유지하면서 B안 수준으로 목표 이해도와 주문 완주 템포가 좋아지는지 확인합니다.

## 알려진 제한
1차 구현은 A/B와의 즉시 비교를 위한 기능 검증본입니다. 드래그 이동, 확률형 Lv.2 생성, 소프트 타이머, 품질 보너스와 실제 자전거 조립 연출은 후속 실험에서 다룹니다.

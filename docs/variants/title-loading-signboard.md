# A안 · 따뜻한 픽셀 공방 간판

관련 이슈: #182 타이틀·로딩 화면 디자인 트랙 · 심사 준비: #117

## 목적

앱 실행 직후 홈 화면 전까지의 첫인상을 목재 간판 로고와 대표 자전거 장면으로 만들고, 로딩 대기를 자전거 바퀴 회전으로 표현합니다. 앱인토스 심사 대표 이미지(스토어 스크린샷) 후보 구도를 겸합니다.

## 화면 구성 (390×810 · 홈 A안 팔레트)

1. 목재 간판: 사슬에 걸린 로고 패널 — DREAM BIKE / GARAGE + 두리 자전거 공방
2. 대표 장면: 드림 바이크(홈 공용 모델) + 정비사 두리(#133 공용)
3. 로딩: 림·스포크 바퀴 회전 + 진행 바(%) — 진행률은 실제 로딩과 연결 가능한 형태, 데모에서는 2.6초 시뮬레이션
4. 준비 완료: ▶ TAP TO START 점멸 → 탭 시 셔터가 밝아지는 홈 전환 연출
5. 하단 버전 표기 (v0.1.0-lab)

## 검증 절차

1. 진입 3초 안에 "자전거 공방 게임"임이 읽히는지 확인합니다.
2. 바퀴 회전과 진행 바가 로딩 중임을 명확히 알리는지, 짧은 로딩에서도 어색하지 않은지 확인합니다.
3. TAP TO START 이후 홈 A안과 같은 공간으로 이어지는 느낌인지 확인합니다.
4. 이 구도를 스토어 대표 이미지로 캡처할 수 있는지 B(출근길)·C(미니 조립)안과 비교합니다.

## 규칙 경계

- 계정·약관 동의·로그인 흐름은 MVP 밖이며 #6 앱인토스 SDK 트랙이 담당합니다.
- 로고 타입은 가칭이며 최종 로고·아이콘 에셋은 #117 심사 준비에서 확정합니다.

## 한계와 후속

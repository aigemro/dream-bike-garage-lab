# Prototype A: MVP 통합 따뜻한 생활형 픽셀 Garage

## 트랙 역할

이 방안은 `RELEASE INTEGRATION > MVP 핵심 기능 통합`(#114)의 기능·판정·상태 전이를 바꾸지 않습니다. 머지 코어 C안의 보드, 택배 수급, 목표 부품 자동 장착과 다음 주문 전환을 같은 코드로 실행하고, `ART & AUDIO`에서 실제 게임 화면의 시각 언어만 검증합니다.

## 디자인 방향

- 홈 화면 A안(#130)의 크림·브라운·골드·그린 팔레트와 굵은 픽셀 외곽선을 작업 화면까지 이어갑니다.
- 목재 벽과 바닥, 공구 페그보드, 창밖 풍경, 택배 선반을 배경에 배치해 한 공간에서 생활하고 일하는 Garage의 느낌을 만듭니다.
- 왼쪽 주문서, 중앙 머지 보드, 오른쪽 택배 선반의 3영역을 명확히 구분해 `주문 확인 → 제작 → 수급`의 위치를 빠르게 찾게 합니다.
- 주문서는 크림 종이, 보드는 목재 작업대, 택배 버튼은 포장 상자처럼 표현하되 텍스트와 상태 배지는 충분한 대비를 유지합니다.
- 실제 브랜드·로고와 특정 게임의 고유 자산·UI는 사용하지 않습니다.

## #114 기능 재사용

이 화면은 별도의 축약 보드나 유사 시뮬레이션을 만들지 않습니다. `startMergePrototype('integrated', 'warm-pixel')`로 #114의 통합 Scene을 그대로 실행합니다.

1. 주문 목표와 현재 장착 상태를 확인합니다.
2. 필요한 카테고리의 택배를 주문하고 배송 후 상자를 개봉합니다.
3. Lv.1 부품을 C안 보드에 배치하고 같은 부품 2개를 2-to-1로 머지합니다.
4. 목표 레벨 부품은 보드에서 한 번만 소비됩니다.
5. 부품 마커가 고객 자전거의 장착 위치로 이동하고 슬롯이 `장착 중 → 장착 완료`로 바뀝니다.
6. 네 부품 장착 후 다음 주문으로 전환하며 남은 보드 부품은 유지합니다.

## 시각 상태 규칙

- 프레임은 코랄 레드, 휠셋은 골드, 구동계는 리프 그린, 핸들바는 작업복 블루로 고정합니다.
- 부품 종류는 색뿐 아니라 픽셀 부품 아이콘(프레임셋·휠셋·체인링·드롭바), 이름, 레벨과 타일 모양을 함께 사용합니다. 주문 부품 목록·택배 선반·보드 조각·미리보기가 같은 아이콘을 공유해 부품 인지가 그림 한 번으로 끝나게 합니다.
- 보드 조각의 대표 칸에는 부품 아이콘과 Lv 배지를 함께 표시하고, Lv.2는 크림·Lv.3 이상은 골드 반짝임 픽셀로 상급 부품을 구분합니다.
- 고객 자전거는 공용 픽셀 스프라이트 모듈(`bike-pixel-sprite`)의 로드/MTB 실루엣으로 그리며, 미장착 부품 그룹은 반투명(부품별 알파)으로 남아 장착 진행이 자전거 위에서 읽힙니다.
- 택배 버튼은 `주문 전`, `배송 중`, `도착`, `배치 중`을 문장으로 표시하고, 주문에 필요한 카테고리는 굵은 테두리와 `주문 필요`로 중복 강조합니다.
- 장착 연출은 홈 A안의 짧고 포근한 픽셀 모션 기준에 맞춰 사각 부품 마커가 자전거 위치로 이동하는 0.52초 피드백을 사용합니다.
- 브라우저에서는 1120×720 게임 캔버스를 가용 영역에 크게 맞춰 보드와 좌우 패널의 판독성을 우선합니다.

## 평가 기준

- 홈 A안에서 PLAY 후 같은 Garage의 작업 공간으로 이어지는가
- 진입 3초 안에 현재 주문, 머지 보드, 택배 수급 위치를 찾는가
- 배경 생활감이 보드 칸·부품 레벨·배송 상태·장착 상태를 방해하지 않는가
- 부품 완성에서 고객 자전거 장착까지 인과관계가 명확한가
- 브라우저 화면에서 보드와 주문·수급 패널이 충분한 크기로 읽히는가

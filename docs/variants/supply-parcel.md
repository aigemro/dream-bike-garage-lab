# 택배 상자 개봉형 부품 수급

## 구현 방식
온라인으로 주문한 부품이 택배 상자로 도착하고, 상자를 탭해 개봉하면 부품이 보드에 추가됩니다. 게임 콘셉트(온라인 부품 주문 → 택배 도착)를 수급 연출로 그대로 살리는 방안입니다.

## 확인할 점
- 개봉 연출이 주는 기대감이 템포 저하보다 큰 가치를 주는지 확인합니다.
- 반복 플레이에서 개봉 단계가 피로 요소로 바뀌는 시점을 관찰합니다.
- 상자 도착 대기와 즉시 개봉 중 어느 쪽이 주문 단위 세션에 맞는지 확인합니다.

## 비교 조건
같은 보드 크기·부품 구성·주문 목표에서 A안(즉시 생성 버튼형)을 기준선으로 템포·기대감·연출 만족도를 비교합니다.

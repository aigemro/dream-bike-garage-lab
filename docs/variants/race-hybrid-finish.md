# C안 · 장거리 사이드뷰 → 결승 중계 전환

## 검증 가설

레이스 전체를 한 시점으로 고정하기보다, 긴 주행 구간은 내 자전거를 따라가는 A안으로 몰입시키고 결승 직전에는 B안의 전체 순위 중계로 전환하면 두 연출의 장점을 함께 살릴 수 있다. 화면 전환 시점과 이유가 명확하면 관람 흐름을 끊지 않고 마지막 순위 경쟁의 긴장감을 높인다.

## 이번 구현

- C안 전용 `리버사이드 3K 챌린지`: A/B안 1,200m보다 긴 3,000m 코스
- 참가비 500·8명 출전·속도 계수·상금은 A/B안과 동일해 연출 차이만 비교
- 0~2,400m(80%): A안 사이드뷰 카메라 추적, 픽셀 라이더·페달링·바퀴 회전·패럴랙스 유지
- 마지막 600m(20%): `LAST 600m · 전체 순위 중계!` 안내와 함께 B안 8레인 전광판으로 자동 전환
- 전환 후 내 레인 골드 강조·실시간 순위 칩·결승 체커로 전체 순위 싸움을 한눈에 표시
- 전환 전후에도 같은 시드 기반 타임라인·현재 거리·기록·배속·최종 정산 결과를 연속 사용
- 순수 로직 테스트로 3,000m 완주, 전환 거리(2,400m), 마지막 중계 거리(600m), A/B와 동일한 보상 조건 검증

## 체험 순서

1. 성장 프리셋을 고르고 참가비 500코인을 내고 출전한다.
2. 2,400m까지 내 자전거를 따라가는 장거리 사이드뷰의 몰입감과 관람 시간을 확인한다.
3. 마지막 600m 진입 시 전환 안내가 보이고 8레인 중계로 자연스럽게 바뀌는지 확인한다.
4. 전광판에서 내 위치와 선두권 변화를 즉시 읽을 수 있는지 본 뒤 결승·정산까지 진행한다.

## 비교 기준

- A안: 짧은 1,200m 전체를 사이드뷰로 관람 — 내 자전거 몰입감 우선
- B안: 짧은 1,200m 전체를 8레인으로 관람 — 전체 순위 가독성 우선
- C안(본 방안): 3,000m의 80%는 사이드뷰, 마지막 20%는 8레인 중계 — 몰입에서 순위 긴장감으로 전환

## 확인할 점

- 3,000m 관람 시간이 지나치게 길지 않은가? 배속 x2가 충분한가?
- 2,400m 전환이 결승 중계의 시작점으로 자연스러운가?
- 화면 전환이 끊김보다 "중계 카메라 전환"으로 느껴지는가?
- 마지막 600m에서 내 레인과 실시간 순위가 즉시 읽히는가?

## 프로토타입 경계

3,000m와 80% 전환 지점은 Lab 체감 검증용 수치다. 참가비·상금·속도 계수는 A/B안과 동일하며, 최종 거리와 연출 채택은 메인 저장소에서 결정한다.

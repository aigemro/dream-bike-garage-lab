# Prototype C: 따뜻한 픽셀 작업 기록 대시보드

## 트랙 역할

이 방안은 통계 항목의 저장 규칙을 다시 결정하지 않습니다. MVP 루프에서 실제로 쌓이는 값(납품·조립·머지·급여·출근·수집)을 홈 A안의 시각 언어로 화면화해, '기록(통계)' 중심 프로필이 반복 플레이 성취를 얼마나 잘 보여주는지 검증합니다. 정보 구조 검토는 `docs/PROFILE_SCREEN_DESIGN_REVIEW.md`를 따릅니다.

## 디자인 방향

- 상단 한 줄에 정비사 초상·닉네임·레벨·직급을 요약하고, 화면 주인공은 숫자 기록으로 둡니다.
- 작업 통계 6종을 2×3 큰 숫자 타일로 배치해 쌓인 양을 먼저 체감시킵니다.
- 주간 기록을 픽셀 막대 그래프로 보여주고 주말 막대는 금색으로 구분합니다.
- 타일을 누르면 상세 설명(승진 조건 연결, 다음 목표 힌트)을 토스트로 보여줍니다.
- 납품 ↔ 머지 기록 전환 버튼으로 그래프의 반복 방문 가치를 확인합니다.

## 공통 조건

- 390×810 세로, 홈 A안과 동일 팔레트
- 동일 프로필 데이터: 정비사 두리 Lv.12, 견습 정비사, 통계 6종(납품 34·조립 12·머지 512·누적 급여 18,500·연속 출근 6일·수집 8/24)
- ← HOME으로 홈 A안 축약 프리뷰(프로필 탭 강조)와 전환하며 진입 흐름을 확인

## 인터랙션

통계 타일 탭 → 상세 설명 토스트. 그래프 전환 버튼 → 주간 납품 ↔ 주간 머지 기록. 주간 데이터는 화면 표현 검증용 고정값이며 실제 저장 범위는 별도 트랙에서 결정합니다.

## 평가 기준

- 진입 3초 안에 '내 작업 기록 화면'임이 읽히는가
- 통계 6타일의 숫자가 390 폭에서 뭉개지지 않는가
- 주간 그래프가 요일별 변화를 읽을 수 있게 전달하는가
- 기록 전환(납품 ↔ 머지)이 더 보고 싶은 동기를 만드는가
- 유저·직급 요약이 통계와 시각적으로 경쟁하지 않는가

## 함께 비교하는 방안

- A안: 따뜻한 픽셀 정비사 사원증 (정체성 중심)
- B안: 따뜻한 픽셀 커리어 승진 보드 (직급 사다리 중심)

세 방안은 같은 프로필 데이터와 홈 A안 진입 흐름을 사용하며, 화면의 주인공만 바꿔 비교합니다.

- 실험 ID: game-core / board-recovery / prototype-b

## 질문
E안은 부품을 옮길 수 없고 맞닿은 쌍만 합성되므로, 어떤 쌍을 먼저 합치느냐에 따라 보드가 막힙니다. 먼저 합칠 쌍을 짚어 주면 초보식 합성에서도 막힘이 줄어드는가? 그러면서 스스로 고르는 재미를 해치지 않는가?

## 규칙
| 항목 | 내용 |
|---|---|
| 추천 시점 | 선택 중이 아닐 때, ① 빈칸이 6칸 이하로 남았거나 ② 8초 동안 입력이 없을 때 |
| 추천 대상 | 합성 쌍 1개. 점수 = 납품 수 × 10000 + 장착 수 × 100 + 합성 뒤 남는 합성 쌍 수 × 10. 점수가 같으면 칸 순서가 빠른 쪽이라 같은 상태면 항상 같은 쌍 |
| 표시 | 두 칸에 노란 테두리가 반짝이고, 안내 문구로 이유를 알려 줌("납품까지 이어져요", "바로 장착돼요", "다음 합성 자리가 남아요") |
| 해제 | 아무 입력이나 하면 사라짐. 조건이 맞으면 다시 나타남 |
| 강제 여부 | 추천과 다른 쌍도 자유롭게 합성할 수 있음 |

규칙 모듈: `src/merge-assist.ts`(`recommendMerge`, `shouldShowHint`) · 테스트: `src/merge-assist.test.ts`

## 시뮬레이션 (주문 30건 × 400회, [경제 시뮬레이터](../balance/E_DAY_C_BALANCE.md) 표 6)
추천을 **항상 따르는** 경우의 상한입니다. 8초 무입력 조건은 봇에 반영하지 않았습니다.

| 플레이어 · 보조 | 주문당 체력 | 막힘을 겪은 회차 | 주문당 반품 |
|---|---|---|---|
| 초보 · 보조 없음(현행) | 7.79 | 34% | 0.084 |
| 초보 · **합성 추천(빈칸 6칸 이하)** | 7.70 | **20%** | 0.025 |
| 초보 · 합성 추천(빈칸 10칸 이하) | 7.66 | 17% | 0.018 |
| 숙련 · 보조 없음 | 7.38 | 4% | 0.004 |

- 막힘 회차가 34% → 20%로 줄고, 반품은 약 1/3로 줄었습니다.
- 추천을 더 일찍(빈칸 10칸 이하) 보여 줘도 효과 차이는 작습니다. 화면을 덜 가리는 6칸 기준을 유지합니다.
- 숙련 수준(4%)까지는 내려가지 않습니다. 막힘 직전에만 추천하므로, 그 전에 쌓인 배치는 바꾸지 못하기 때문입니다.

## 체험 방법
1. 부품 상자를 계속 열어 보드를 채웁니다.
2. 빈칸이 6칸 이하가 되면 노랗게 반짝이는 두 부품과 안내 문구가 나타납니다.
3. 아무 입력이나 하면 추천이 사라지고, 8초 동안 쉬면 다시 나타납니다.
4. 진행은 기준선 E v3와 따로 저장됩니다.

## 확인할 것 (사람 플레이)
- 추천을 따르는 비율과 합성 결정 시간
- 추천이 "정답 강요"로 느껴지는지, 퍼즐 재미가 줄어드는지
- 막혔을 때 이유를 설명할 수 있는지

## 메인 적용 시 참고
화면에 노란 강조 테두리와 안내 문구가 추가됩니다. 등급분류 화면에 포함되므로 출시 포함 여부를 함께 판단해야 합니다.

# 고정 급여·직선 성장

## 구현 방식
자전거를 납품할 때마다 정해진 급여를 받고, 모은 급여로 정해진 순서의 성장 항목을 차례로 해금합니다. 보상과 성장 경로가 모두 예측 가능한 기준선 방안입니다.

## 확인할 점
- 예측 가능한 보상이 안정적인 반복 플레이 동기를 만드는지 확인합니다.
- 성장 경로가 단조로워 목표 의식이 빨리 소진되지 않는지 관찰합니다.
- 급여 수치가 주문 난이도와 자연스럽게 연결되는지 확인합니다.

## 비교 조건
같은 주문 구성·납품 횟수에서 B안(성과 보너스·성장 선택), C안(소프트 타이머)과 보상 체감·다음 플레이 동기를 비교합니다.

# A안: 부품별 순차 자동 장착

## 가설

주문 부품이 완성될 때 해당 부위가 즉시 작업대로 이동하고 장착되면, 머지 흐름을 끊지 않으면서도 자전거가 만들어지는 과정을 인지할 수 있습니다.

## 규칙

- 부품 완성 입력 직후 해당 부품의 이동 연출을 시작합니다.
- 프레임·휠셋·구동계·핸들바는 각자의 위치에 장착됩니다.
- 장착 전 부위는 낮은 명도의 실루엣으로 표시합니다.
- 장착 후 부위는 고유 색상으로 활성화합니다.
- 네 부품이 모두 장착되면 납품 준비 상태로 전환합니다.

## 확인 항목

- 사용자가 어느 부품이 어느 위치에 장착됐는지 이해하는가
- 0.5초 안팎의 연출이 반복 머지 흐름을 방해하지 않는가
- 완성차가 한 번에 나타나는 방식보다 조립 성취감이 높아지는가

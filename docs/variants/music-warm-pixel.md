# Prototype A: 포근한 Garage 칩튠 루프

## 공통 기준

홈 화면 디자인 A안의 햇살 드는 목재 공방을 80 BPM, C Major, 8스텝의 짧은 칩튠으로 표현합니다. 외부 음원이나 특정 게임의 멜로디를 사용하지 않고 Web Audio로 실시간 생성하는 검증용 데모입니다.

## 음악 방향

- HOME은 둥근 삼각파와 여유 있는 저음으로 소유·휴식 공간을 표현합니다.
- WORK는 짧은 사각파와 빠른 펄스로 머지 작업의 집중감을 더합니다.
- 두 상태는 같은 음계와 진행을 공유해 전환 시 다른 게임처럼 끊기지 않게 합니다.
- 음악은 사용자 PLAY 입력 후에만 시작하며 STOP과 화면 이탈 시 즉시 종료됩니다.

## 체험 방법

PLAY MUSIC을 누르고 HOME·WORK를 번갈아 선택해 루프의 연결, 상태 차이와 반복 피로를 확인합니다.

## 평가 기준

- HOME과 WORK의 분위기 차이가 과도한 대비 없이 느껴지는가
- 짧은 루프가 여러 번 반복되어도 멜로디가 피로하지 않은가
- 화면의 포근한 픽셀 감성과 음색이 일치하는가
- 사용자 입력·정지·화면 이탈 시 오디오 생명주기가 안전한가

# 주문 목표 중심 머지

## 구현 방식
고객 주문에 필요한 부품과 단계를 먼저 제시하고 해당 목표를 향해 머지합니다.

## 1차 구현 범위
- A안과 동일한 6×7 보드·4종 부품·Lv.1~Lv.4 조건
- 주문 3종과 부품별 목표 레벨·진행 상태 표시
- 미완료 주문에 필요한 부품을 우선 생성
- 목표 부품 완성 시 자동 납품과 다음 주문 전환
- 시간·행동·머지·오입력·빈 칸 수 실시간 표시

## 2차 구현 범위
- 텍스트 주문 목록을 완성 자전거 미리보기와 부품별 요구 카드로 시각화
- 프레임·휠셋·구동계·핸들바의 요구 레벨과 완료 여부를 한눈에 표시
- 주문 번호·자전거 종류·전체 진행 수를 하나의 주문 카드 안에 구성

이번 범위는 주문을 어떻게 보여줄지에만 한정합니다. 부품 장착 애니메이션, 단계별 자전거 조립, 납품 연출은 `주문과 조립` 트랙에서 별도 방안으로 비교합니다.

## 후속 적용 범위
- Prototype A의 보드 행·열 직접 입력과 화면 크기 대응
- 부품 선택 버튼의 보드 하단 배치
- 실제 부품 형태에 가까운 크기·점유 칸·회전·이동 규칙

## 확인할 점
자유 보드보다 목표성과 플레이 템포가 좋아지는지 비교합니다.

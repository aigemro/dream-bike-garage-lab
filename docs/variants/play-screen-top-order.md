# Prototype A: 주문 상단 통합형

## 핵심 가설
- 주문 목표를 상단에 고정하면 부품 제작 중에도 필요한 레벨과 진행 상태를 놓치지 않는다.
- 부품 제작과 조립 결과를 좌우에 함께 보여주면 전체 플레이 흐름을 한눈에 이해할 수 있다.

## 동일 비교 조건
- 로드바이크와 MTB 주문이 번갈아 등장한다.
- 프레임 Lv.3, 휠셋 Lv.2, 구동계 Lv.2, 핸들바 Lv.1을 제작한다.
- 모든 부품은 Lv.1부터 시작하며 같은 레벨 2개가 자동 머지된다.
- 조립과 납품 후 1,500코인을 받고 다음 주문으로 전환된다.

## 확인할 점
- 주문 패널과 보드가 겹치지 않는가
- 목표와 제작 상태를 시선 이동 없이 비교할 수 있는가
- 브라우저 화면에서 하단 버튼까지 안정적으로 보이는가

# 통합안: 머지 코어 C안 + 택배 수급 + 장착·조립

## 목적

별도의 축약형 보드를 새로 만들지 않고, 실제 머지 코어 C안(자유 보드 + 주문 가이드)의 화면과 로직 위에 택배형 부품 수급과 부품별 장착·조립 과정을 직접 연결해 MVP 핵심 기반이 하나의 흐름으로 동작하는지 검증합니다. 디자인 개선은 다루지 않으며 기능 연결, 상태 전이, 진행 차단 조건만 확인합니다.

## 기준 구현

- 기반: 머지 코어 C안 (`merge-prototype.ts`)의 `integrated` 모드. 자유 배치형 보드, 부품 형상·회전, 주문 가이드, 고객 자전거 패널, 2→1 머지 규칙을 그대로 사용합니다.
- 부품 수급: 즉시 생성 버튼 대신 카테고리 선택형 택배(#72 방식)로 대체합니다. 주문 → 배송 대기 → 상자 개봉 → 보드 배치 순서이며, 개봉한 Lv.1 부품은 C안과 동일한 부품 데이터와 배치·회전 규칙을 사용합니다.
- 주문 조립: 목표 레벨 부품 완성 시 즉시 납품 처리하지 않고, 보드에서 부품을 소비한 뒤 고객 자전거의 장착 위치로 이동하는 단계별 자동 장착 연출(#151 방식)을 거칩니다. 장착 위치·상태는 주문 패널의 부품 슬롯과 자전거 그림(프레임·휠셋·구동계·핸들바)에 반영됩니다.
- 주문 완료: 모든 주문 부품이 장착되면 주문 완료 상태로 전환하고 다음 주문이 도착합니다. 보드에 남은 부품은 다음 주문에서 계속 사용할 수 있습니다.

## 통합 플레이 흐름

1. C안 화면에서 현재 주문과 목표 부품 레벨을 확인합니다.
2. 오른쪽 패널에서 필요한 카테고리의 택배를 주문합니다. 주문에 필요한 카테고리는 강조 표시됩니다.
3. 배송이 끝나면 같은 버튼으로 상자를 개봉하고, 보드에서 배치 위치를 선택합니다. 개봉 후 버튼을 다시 누르면 90° 회전합니다.
4. C안의 선택·이동·회전 조작과 2→1 규칙으로 목표 레벨까지 머지합니다. 잘못 선택했을 때는 **선택 취소**로 보드 변경 없이 해제하며, 미배치 택배는 도착 상태로 되돌아갑니다.
5. 목표 부품이 완성되면 보드에서 소비되어 자전거로 이동하는 장착 연출과 함께 자동 장착됩니다.
6. 부품 슬롯이 '장착 중… → 장착 완료'로 바뀌고 자전거 그림의 해당 부위가 채워집니다.
7. 모든 부품 장착 후 주문 완료로 전환되고 다음 주문이 시작됩니다.

## 검증 항목

- 기존 C안의 보드 상호작용(배치·회전·이동·머지)과 주문 가이드가 그대로 유지되는가
- 택배 주문·배송·개봉·배치의 상태 전이가 명확하고 부품 데이터가 중복 관리되지 않는가
- 부품 선택·택배 수동 배치를 취소해도 보드와 도착 택배 상태가 유실되지 않는가
- 목표 부품이 정확히 한 번만 소비·장착되는가 (중복 장착 없음)
- 여러 부품이 동시에 완성돼도 장착 연출이 순차적으로 안정 진행되는가
- 모든 부품 장착 시 주문 완료로 전환되고 다음 주문이 정상 시작되는가

# Garage 로비·플레이 분리형 메인 홈

## 구현 방식
모바일 수집·레이싱 게임에서 사용하는 Garage Lobby / Collection Hub 패턴을 적용합니다. 메인 홈의 중앙에는 대표 자전거와 Garage 전시 공간을 두고, 보유 자전거 수·도감 진행률·다음 해금 목표를 보여줍니다. 하단 PLAY 버튼을 누르면 머지 보드 중심의 별도 게임 화면으로 전환됩니다.

## 확인할 점
- 자전거를 소유하고 수집한다는 느낌이 A/B/C보다 강한지 확인합니다.
- 홈과 게임 화면을 분리해 각 화면의 목적이 명확해지는지 관찰합니다.
- 실제 플레이까지 탭이 한 번 늘어나는 부담이 허용 가능한지 확인합니다.
- 추후 Garage 꾸미기·자전거 성장·시즌 전시 기능을 확장하기 쉬운지 검토합니다.

## 비교 조건
A/B/C와 동일한 스태미너·코인·주문·보드 데이터를 사용합니다. D안만 메인 홈과 머지 플레이를 두 화면으로 분리하며 PLAY와 HOME으로 왕복할 수 있습니다.

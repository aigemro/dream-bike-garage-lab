# localStorage 저장

## 구현 방식
작은 JSON 상태를 브라우저 localStorage에 저장하고 시작 시 복구합니다.

- 보드 부품, 보유 코인, 현재 주문을 하나의 JSON으로 직렬화합니다.
- `schemaVersion`, `revision`, `savedAt`을 함께 저장합니다.
- 단일 슬롯 저장·불러오기·삭제 흐름을 직접 체험할 수 있습니다.

## 검증 순서
- 상태 변경 후 현재 상태 저장
- 새로고침 또는 화면 재진입
- 저장 상태 불러오기 후 값 비교
- 저장 삭제 후 데이터 없음 안내 확인
- 화면 재진입·새로고침 시 마지막 저장 상태 자동 복원
- 손상되거나 지원하지 않는 데이터의 안전한 거부와 오류 안내

## 확인할 점
MVP 규모에서 단순성과 안정성이 충분한지 확인합니다.

서버는 필요하지 않지만 브라우저 데이터가 삭제되거나 다른 기기로 이동하면 복구할 수 없습니다.

# A안 · 1회 무료 정리

## 검증 목적

보드가 가득 차고 유효 머지가 없을 때, 낮은 레벨의 불필요 부품을 한 번 무료로 정리하는 규칙이 과도한 실패감 없이 플레이를 복구하는지 확인합니다.

## 1차 구현

- 6×7 보드의 진행 불가능 상태 자동 감지
- 빈 칸과 유효 머지 수를 진단 메시지로 표시
- 불필요 부품 한 개 무료 정리
- 확보한 공간에 주문 부품 보급 후 유효 머지까지 연결
- 복구 사용 횟수와 복귀 행동 수 표시

## 비교 예정

- B안: 코인을 사용해 원하는 부품 정리
- C안: 불필요 부품을 현재 주문 부품으로 교환

## 관찰 항목

- 막힘 원인과 복구 방법을 바로 이해하는가
- 무료 정리가 손실감 없이 공정하게 느껴지는가
- 복구 이후 자연스럽게 다음 머지로 돌아가는가

# Prototype D: 모던 캐주얼 모바일 Garage

## 트랙 역할

이 방안은 게임 구조를 다시 결정하지 않습니다. GAME CORE > 메인 홈·플레이 화면 > E안에서 합의한 Garage 홈 정보 구조를 고정한 채, A안과 완전히 동일한 데이터 조건에서 홈 화면의 시각 언어만 비교합니다.

## 디자인 방향

- 요즘 모바일 캐주얼(머지·퍼즐) 게임에서 널리 쓰는 밝고 글로시한 벡터 UI를 채택합니다. 픽셀아트가 아니라 매끈한 라운드 카드 문법입니다.
- 배경은 하늘색에서 민트로 떨어지는 세로 그라데이션 위에 부드러운 언덕 실루엣과 구름을 배치하고, Garage는 밝은 나무톤의 오픈 쇼룸 무대로 표현합니다.
- 정보는 흰색 라운드 카드에 담고, 카드 아래에 소프트 섀도를 깔아 외곽선 없이도 영역을 구분합니다.
- 버튼은 캡슐형과 원형 아이콘 버튼으로 통일하고, 위쪽 하이라이트 밴드로 글로시한 질감을 만듭니다.
- 하단 PLAY는 노랑에서 주황으로 이어지는 그라데이션 캡슐로 화면에서 가장 눈에 띄게 만듭니다.
- 중앙 드림 바이크는 채도 높은 파랑·시안 프레임의 로드바이크 스타일로 그리고, 밝은 원형 전시 단상과 은은한 방사형 하이라이트 위에 올려 화면의 주인공으로 세웁니다.
- 특정 게임의 고유 자산·캐릭터·타일·UI를 복제하지 않고 독자적인 자전거 쇼룸 화면으로 구성합니다.

## 회의안 반영

1. 중앙: 나의 대표 자전거와 Garage 성장
2. 하단 중앙: 가장 큰 PLAY 버튼
3. 상단: 에너지·코인·현재 주문
4. 좌측: 이벤트·랭킹
5. 우측: Tour·조립·Status
6. 중앙 하단: 수집률과 다음 해금 목표

## 인터랙션

PLAY를 누르면 축약된 주문·머지 화면으로 이동하며, HOME으로 돌아오면 플레이 결과가 Garage에 축적될 것이라는 흐름을 확인할 수 있습니다. 보조 메뉴는 현재 정보 계층만 검증하는 토스트 피드백 버튼입니다.

## 평가 기준

- 익숙한 캐주얼 모바일 UI 문법이 신규 유저의 진입 장벽을 낮추면서 Garage 고유의 공방 감성을 잃지 않는가
- 3초 안에 대표 자전거와 PLAY를 찾는가
- 흰 카드와 소프트 섀도가 그라데이션 배경 위에서 정보 계층을 명확하게 유지하는가
- 글로시 하이라이트와 채도 높은 색이 반복 노출 시 피로하지 않은가
- 390×810 세로 화면에서 터치 영역과 텍스트가 읽히는가

## A안과의 비교 포인트

- A안은 굵은 외곽선과 종이·나무 질감으로 공방의 생활감을 만들고, D안은 외곽선 없는 흰 카드와 그라데이션으로 매끈한 첫인상을 만듭니다.
- 같은 정보 구조와 데이터를 두고 픽셀 감성과 캐주얼 벡터 감성 중 어느 쪽이 신규 유저의 이해 속도와 재방문 감정에 유리한지 비교합니다.
- 버튼 인지: A안의 두꺼운 테두리 사각 버튼과 D안의 원형 아이콘·캡슐 버튼 중 어느 쪽이 오탭 없이 빠르게 눌리는지 확인합니다.
- 공방 감성 유지: 밝은 쇼룸 연출이 Garage를 성장하는 나의 공간으로 느끼게 하는지, 아니면 범용 캐주얼 게임처럼 보이게 하는지 관찰합니다.

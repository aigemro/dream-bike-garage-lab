# 머지 코어 D안 · 입고 정리형 인접 머지

- 실험 ID: game-core / merge / prototype-d / v1
- 상태: 검토 준비 (독립 데모), 채택 여부: 미결정
- 관련 이슈: [#243](https://github.com/aigemro/dream-bike-garage-lab/issues/243)

## 질문과 가설
자전거 가게 알바가 입고 재고를 정리하고 고객 자전거를 조립하는 흐름에서, 1칸 부품과 체력 기반 공급이 기존 C안보다 반복 조작을 간단하게 만드는가?

사장님이 거래처에 주문한 혼합 부품 상자에서 알바가 하나씩 부품을 꺼냅니다. 공급 버튼은 `입고 정리`이며, 랜덤인 것은 종류·레벨입니다. 위치는 아래쪽 왼쪽부터 오른쪽, 그다음 위 행 순서로 결정합니다. 다음 칸은 점선으로 표시합니다. 상자는 보드 밖에 있어 칸을 차지하지 않습니다.

## 유지하는 컨셉
프레임·휠셋·구동계·핸들바 4종과 Lv.1~4를 유지합니다. 완성차는 머지하지 않고, 요구 레벨 이상의 부품을 직접 장착하여 조립·납품합니다. 급여 500 C와 3단계 드림 바이크 성장을 독립 데모에서 연결합니다. 기존 통합 성장 저장소를 변경하지 않습니다.

## 핵심 규칙
- 보드 6×7, 모든 부품은 1칸. 탭 선택 후 대상 탭 또는 포인터 드래그로 이동·교환.
- 동일 종류·동일 레벨의 상하좌우 연결 그룹에서 선택 칸을 시작으로 탐색한 3칸을 강조. ㄴ자 허용, 대각선·행 경계 연결 불허.
- `3개 머지`로 강조한 3칸만 소비하고 선택 위치에 상위 1개 생성. 4개 이상이어도 나머지는 보존. Lv.4는 머지 불가. 자동·연쇄 머지와 5개 보너스는 제외.
- 30 체력으로 시작, 입고당 1 차감. 이동·머지·장착은 무료. 체력이 없거나 빈칸이 없으면 공급과 차감을 함께 차단.
- 실제 시간 10분당 1 회복. 오프라인 경과 시간과 미완료 회복 간격 보존. 최대 30, 만충 이후 시간은 비축하지 않음. Day와 별도.
- 입고 레벨: Lv.1 80%, Lv.2 20%. 종류: 70%는 미장착 종류 중 균등, 30%는 전체 4종 중 균등. 미장착 종류가 4회 연속 나오지 않으면 다음 공급에 보장. 개별 특정 종류의 천장은 아님.
- 첫 주문은 지급 부품만으로 완료 가능. 이후 3종의 요구 레벨 Lv.1~2 주문을 순환. 남은 부품은 보존.
- 재고 반납은 확인 후 부품 삭제, 체력 환급 없음. 잘못 장착하거나 미완성 납품은 차단.
- D안 전용 localStorage 저장. 유효하지 않은 데이터는 초기 상태 복구, 저장 불가 시 화면에 안내. 단일 탭 실험이며 다중 탭·서버 시간 검증은 범위 밖.
- 랩 도구: 체력 충전, 화면 내 10초당 1 회복 가속(재진입 시 OFF), 확인을 거치는 D안 초기화.

## 비교 대상과 평가
기존 C안과 동일한 자전거 조립 목표·부품 4종·레벨 체계를 비교합니다. 공급/머지 규칙이 달라 주문 난이도는 완전히 동일하지 않습니다. 수치 확정이나 속도 우열을 단순 비교하지 않습니다.

- 첫 주문을 설명 없이 완주할 수 있는가?
- 탭·드래그·머지 대상 강조가 의도대로 작동하는가?
- 랜덤 입고가 기대감을 주는가, 필요한 종류가 안 나와 답답한가?
- 공급·머지 횟수, 납품 수, 정체 시간을 기록한다.
- 체력이 0이어도 남은 부품으로 할 일이 있는가?
- 기존 C안 대비 조립 알바라는 느낌과 재플레이 의향을 평가한다.

## 실행 방법
Lab → MVP 핵심 플레이 → 머지 코어 → D안 → 체험 화면.
직접 경로: `#/track/merge-core/intake-merge/demo`.
첫 주문: 좌상단 프레임 3개 머지·장착 → 휠셋 3개 머지·장착 → 구동계·핸들바 장착 → 납품 → 내 드림 바이크 성장.
테스트 도구는 조작 안내 안에 있습니다. 상단 초기화도 D안 저장을 확인 후 초기화합니다.

## 검증 결과
자동 규칙 테스트: 첫 주문 완주·중복 납품·성장 비용, 인접성·소비 대상, 최대 레벨, 포화/체력 차감, 공급 보정, 오프라인 회복·만충·시계 역행, 저장 손상, 이동·잔여 부품 보존.
빌드 및 화면 검증 결과는 PR에 기록합니다. 실제 사용자 C/D 비교, 장기 밸런스, 앱인토스 실기기 검증은 후속입니다.

## 기준 자료와 메인 반영
첨부 머지게임 설계안의 부품→조립→급여 흐름을 유지하고, 이번 요청에 따라 수급과 2-to-1 규칙을 D안에서 변경합니다. Merge Gardens의 3개 머지는 참고하되 동일한 게임 규칙 전체의 복제는 아닙니다.
일반 프로젝트 반영은 비교 후 별도 결정합니다. 이번에는 Lab 프로토타입만 추가합니다.

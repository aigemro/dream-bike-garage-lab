# 즉시 생성 버튼형 부품 수급

## 구현 방식
생성 버튼을 누르면 부품이 지연 없이 곧바로 보드에 추가됩니다. 현재 머지 프로토타입이 사용하는 방식으로, 다른 수급 방안과 비교할 때의 기준선입니다.

## 확인할 점
- 지연 없는 공급이 머지 플레이 템포를 가장 잘 유지하는지 확인합니다.
- 공급이 너무 쉬워서 부품 획득의 기대감이 사라지지 않는지 확인합니다.
- 보드가 가득 찼을 때의 처리(생성 불가 안내)가 자연스러운지 확인합니다.

## 비교 조건
같은 보드 크기·부품 구성·주문 목표에서 B안(택배 상자 개봉형), C안(쿨다운·충전식 생성기형)과 템포·기대감·이해도를 비교합니다.

# Prototype A: 종이·목재 픽셀 공방 UI

## 공통 기준

홈 화면 디자인 A안의 종이 카드, 목재 프레임, 크림·브라운·골드 팔레트를 주문·부품·재화·상태 UI에 확장합니다. 작은 픽셀 배경 위에서도 정보가 먼저 읽히도록 장식보다 경계와 상태 대비를 우선합니다.

## 표현 방향

- 주문 카드는 자전거 실루엣, 진행 문구와 필요 부품을 한 화면에 묶습니다.
- 휠·프레임·핸들·안장은 서로 다른 외곽 형태로 구분합니다.
- READY·부족·잠금은 색상뿐 아니라 체크, 수량 문구와 LOCK 배지를 함께 사용합니다.
- 코인·에너지·직급은 홈 A안 상단 바와 같은 아이콘 언어를 유지합니다.
- 버튼과 타일은 굵은 외곽선과 그림자로 터치 가능한 영역을 분명히 합니다.

## 체험 방법

기본·완료 가능·잠금 상태를 전환해 같은 부품 아이콘이 상태에 따라 어떻게 달라지는지 확인합니다.

## 평가 기준

- 상태가 색상에 의존하지 않고 3초 안에 구분되는가
- 따뜻한 종이·목재 질감이 정보 가독성을 방해하지 않는가
- 44px 이상 터치 영역과 작은 텍스트가 세로 화면에서 유지되는가
- 홈·주문·머지 화면으로 확장 가능한 일관된 체계인가

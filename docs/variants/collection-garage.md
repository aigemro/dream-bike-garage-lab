# Garage 전시

## 구현 방식
획득한 자전거를 Garage 슬롯에 배치하고 대표 자전거와 성장 상태를 보여줍니다.

## 확인할 점
도감보다 강한 소유감과 애착을 제공하는지 확인합니다.

## 검토 의견 (2026-08-08)

### 의도 일치
슬롯 배치 + 감상(전시대 3칸)과 성장 상태(레벨/성장 버튼)는 구현되었으나, 문서와 어긋나는 부분이 있습니다.

- **대표 자전거 개념 부재**: 문서의 "대표 자전거"에 해당하는 지정/표시 기능이 없고 '대표 후보' 라벨만 있습니다.
- **문구-동작 불일치**: "전시 자전거를 성장시킵니다"라고 안내하지만 실제로는 전시대 배치 여부와 무관하게 선택된 자전거가 성장합니다(`src/collection-prototype.ts:180-187`).

### 발견된 문제
- **같은 자전거 중복 전시 가능**: 슬롯 클릭 시 중복 검사가 없어(`src/collection-prototype.ts:162-165`) 한 자전거를 3칸 모두에 배치할 수 있습니다. 소유감·애착 검증이라는 실험 질문에 중복 전시는 노이즈이므로, 배치 시 기존 슬롯에서 제거하는 1~2줄 수정을 권장합니다. 또한 슬롯을 비우는 방법이 없습니다(교체만 가능).
- **성장 레벨 상한 없음**: C안은 Lv.4 캡이 있는데 B안은 캡이 없어 규칙이 비대칭입니다(현재 코인으로는 Lv.4가 실질 상한이라 당장 드러나지 않음). 캡을 명시하거나 캡 없음을 의도로 문서화 필요.
- 공통 문제(렌더 객체 누수 `removeAll()`, 모바일 세로 축소)는 [collection-catalog.md](collection-catalog.md) 검토 의견 참고.

### 개선 제안
- "도감보다 강한 소유감"을 검증하려면 대표 자전거 지정(탭하면 대표 뱃지) 정도의 최소 기능이 실험 질문에 직접 닿습니다. 중복 전시 금지와 함께 소규모 수정으로 가능합니다.

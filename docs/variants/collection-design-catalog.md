# Prototype A: 따뜻한 픽셀 자전거 도감

## 트랙 역할

이 방안은 수집 규칙을 다시 결정하지 않습니다. `GAME CORE > 자전거 수집 > A안(도감형)`의 빈칸 채우기 구조를 홈 화면 디자인 A안(따뜻한 생활형 픽셀 Garage)의 시각 언어로 실제 화면화해, 홈 하단 자전거 탭에서 진입하는 도감 화면의 가독성과 수집 동기를 검증합니다.

## 디자인 방향

- 크림·종이·목재 팔레트와 굵은 외곽선으로 홈 A안과 같은 공방 감성을 유지합니다.
- 24종 전체를 4×6 그리드 한 화면에 담아 수집의 전체 규모를 먼저 보여줍니다.
- 보유 자전거는 색이 있는 픽셀 자전거로, 미획득은 어두운 실루엣과 `?`로 구분합니다.
- 다음 목표(TRAIL MTB)는 붉은 테두리와 NEXT 태그로 도감 안에서 강조합니다.
- 칸을 누르면 하단 상세 카드에 이름·분류·등급·획득 힌트를 보여줍니다.

## 공통 조건

- 390×810 세로, 홈 A안과 동일 팔레트
- 동일 수집 데이터: 24종 중 8종 보유, 코인 2,480, 에너지 72/100
- ← HOME으로 홈 A안 축약 프리뷰와 전환하며 자전거 탭 진입 흐름을 확인

## 인터랙션

도감 칸 선택 → 하단 상세 카드 확인 → 미획득 자전거는 획득 연출 미리보기로 칸이 채워지는 피드백을 확인합니다. 획득 조건과 보상 수치는 이 트랙에서 결정하지 않습니다.

## 픽셀 스프라이트 개선 (2차)

- 도감 칸의 자전거를 공용 픽셀 스프라이트 모듈(`bike-pixel-sprite`)로 교체했습니다. 카테고리별 실제 자전거 실루엣(로드 드롭바 / MTB 서스펜션 포크·노브 타이어 / 그래블 탑튜브 백 / 미니벨로 작은 바퀴·긴 싯포스트)이 1px 셀 크기에서도 구분됩니다.
- 미획득 칸은 같은 실루엣을 단색 그림자 모드로 그려, 어떤 종류의 자전거가 올지 실루엣으로 예고하며 수집 동기를 만듭니다.

## 평가 기준

- 진입 3초 안에 '도감을 채우는 화면'임이 읽히는가
- 24칸 그리드에서 보유·미획득·다음 목표가 구분되는가
- 칸 선택 → 하단 상세 카드의 시선 흐름이 자연스러운가
- 미획득 칸의 힌트가 주문 플레이 동기로 이어지는가
- 반복 노출 시 그리드 밀도가 피로하지 않은가

## 함께 비교하는 방안

- B안: 따뜻한 픽셀 Garage 전시 (전시대 배치·내 공간 경험)
- C안: 따뜻한 픽셀 드림 바이크 성장 (한 대 집중 성장)

세 방안은 같은 수집 데이터(8/24)와 홈 A안 진입 흐름을 사용하며, 수집을 보여주는 형태만 바꿔 비교합니다.

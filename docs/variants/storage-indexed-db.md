# IndexedDB 저장

## 구현 방식
구조화된 게임 상태와 여러 저장 슬롯을 IndexedDB에 비동기로 저장합니다.

- 보드 부품, 보유 코인, 현재 주문을 구조화 객체로 저장합니다.
- `schemaVersion`, `revision`, `savedAt`을 함께 저장합니다.
- 세 개의 슬롯에 서로 다른 상태를 저장·불러오기·삭제할 수 있습니다.

## 검증 순서
- 슬롯을 선택하고 상태 변경 후 저장
- 다른 슬롯에 서로 다른 상태 저장
- 새로고침 또는 화면 재진입
- 슬롯별 복원 결과와 분리 여부 확인

## 확인할 점
버전 변경과 데이터 마이그레이션을 관리하기 쉬운지 확인합니다.

서버는 필요하지 않으며, 계정 복구와 기기 간 이어하기는 후속 서버 동기화 실험에서 다룹니다.

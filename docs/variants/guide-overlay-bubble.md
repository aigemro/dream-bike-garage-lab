# A안 · 따뜻한 픽셀 정비사 말풍선

관련 이슈: #180 첫 플레이 안내 오버레이 디자인 트랙 · 규칙 기준: #115

## 목적

첫 주문 완주(주문 확인 → 택배 → 개봉·배치 → 머지 → 자동 장착 → 납품) 6단계 안내를, 정비사 두리의 말풍선과 스포트라이트 강조로 전달하는 캐릭터 중심 표현입니다. 안내 문구·발동 조건 규칙은 #115에서 비교하며 여기서는 표현만 검증합니다.

## 화면 구성 (390×810 · 게임 화면 B안 모사 배경)

- 배경: 게임 화면 B안(#177) 레이아웃의 정적 모사 (주문 카드·6×7 보드·택배 선반)
- 스포트라이트: 강조 영역만 남기고 사방을 어둡게 덮는 4분할 딤 + 점멸 픽셀 테두리
- 정비사 두리(#133 공용 캐릭터) + 말풍선: 강조 영역 반대편에 배치해 대상을 가리지 않음
- 진행 표시(1/6~6/6), [다음 →]/[시작하기 ▶] 버튼, 상단 [건너뛰기 ✕]
- 종료·건너뛰기 후 [안내 다시 보기 ↺] 진입점 제공

## 검증 절차

1. 각 단계에서 강조 영역과 말풍선이 서로 가리지 않는지 확인합니다 (특히 2단계 택배 선반·3~4단계 보드).
2. 다음 행동 대상을 3초 안에 찾을 수 있는지 확인합니다.
3. 건너뛰기와 다시 보기가 항상 접근 가능한지 확인합니다.
4. 캐릭터 등장이 따뜻한 Garage 분위기를 강화하는지 B(종이 메모)·C(하이라이트)안과 비교합니다.

## 한계와 후속

- 배경은 상호작용 없는 정적 모사로, 실제 게임 화면 B안 위 실시간 오버레이 결합은 표현 채택 후 #115 규칙 검증과 함께 진행합니다.
- 행동 감지형 진행(버튼이 아닌 실제 행동으로 다음 단계)은 #115의 B안 규칙과 결합해 검토합니다.

# B안 · 8레인 전광판 중계 레이스

## 검증 가설

자동 관람형 대회에서 중요한 것은 주행 몰입보다 순위 경쟁의 가독성이다. 트랙 전체를 8레인 전광판으로 중계하면 누가 앞서고 뒤처지는지 매 순간 한눈에 읽혀, 결과 발표의 긴장감이 더 커진다.

## 이번 구현

- A안과 동일한 `race-progress.ts` 시뮬레이션 결과(같은 시드 → 같은 레이스)를 다른 연출로 재생
- 다크우드 전광판 위 8개 레인: 참가자 이름·실시간 순위 칩·결승 체커를 레인마다 표시
- 내 레인은 골드 테두리로 강조, 자전거는 텍스처 캐시 경로(cell 1)로 8대 동시 렌더링
- 상단 HUD·미니맵 진행 바·구간 배너·배속 토글·정산 흐름은 A안과 완전히 동일 (연출만 비교)
- 참가 화면·성장 프리셋(갓 완성/성장 중/드림 완성)·상금표도 A안과 동일 조건

## 체험 순서

1. A안과 같은 성장 프리셋으로 참가비 500코인을 내고 출전한다.
2. 레인별 순위 칩이 오르막·내리막에서 뒤바뀌는 것을 확인한다.
3. 내 레인(골드 테두리)이 전체 8명 중 어디쯤인지 즉시 읽히는지 확인한다.
4. 정산 후 A안과 비교해 어느 쪽이 "다음 대회를 위해 자전거를 키우고 싶다"는 동기를 더 만드는지 기록한다.

## 비교 기준

- A안: 사이드뷰 카메라 추적 — 내 자전거 몰입감 우선
- B안(본 방안): 전광판 전체 조망 — 순위 경쟁 가독성 우선

## 프로토타입 경계

A안과 같은 수치·시뮬레이션을 사용하며, 연출 채택 결정은 메인 저장소 담당이다. 두 안의 관람 체감 비교 결과를 이슈 #231에 기록한다.

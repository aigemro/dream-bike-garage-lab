# Prototype A: 짧고 포근한 픽셀 모션

## 공통 기준

홈 화면 디자인 A안의 부드럽고 생활감 있는 분위기를 유지하면서 머지 플레이의 속도를 늦추지 않는 0.4초 이하 모션을 검증합니다. 연출 중에도 다음 판단이 가능하도록 긴 입력 차단과 카메라 이동은 사용하지 않습니다.

## 모션 문법

- 머지: 두 부품 흡착 → 짧은 스쿼시 → 1회 반짝임
- 장착: 부품 낙하 → 작게 튀는 체결 → 1회 반짝임
- 완성: 크림색 와이프 → 자전거 강조 → 즉시 원래 화면 복귀
- 결과마다 이동 방향과 길이를 다르게 해 행동을 형태로도 구분합니다.

## 체험 방법

MERGE·장착·완성 버튼을 여러 번 눌러 결과 인지, 다음 입력 가능 시점과 반복 피로를 확인합니다.

## 평가 기준

- 소리 없이도 어떤 행동이 완료됐는지 구분되는가
- 연출이 0.4초 안에 끝나고 다음 입력을 방해하지 않는가
- 굵은 픽셀 형태가 확대·축소 중 흐려지거나 떨리지 않는가
- 반복 실행 시 반짝임과 흔들림이 과도하지 않은가

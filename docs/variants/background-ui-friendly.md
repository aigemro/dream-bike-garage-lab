# Prototype C: 픽셀 배경 + 캐주얼 UI 친화형

## 가설

픽셀 생활감은 유지하되 소품과 명암을 단순화하고 저밀도 영역을 확보하면 모바일 주문·PLAY·성장 UI를 가장 안정적으로 수용할 수 있습니다.

## 공통 조건

- 390×810 세로 모바일 화면
- 좌측 작업대, 중앙 정비 스탠드, 우측 주문 게시판과 출입문
- 실제 브랜드·로고 미사용
- UI를 배경에 합성하지 않고 상·하단 오버레이 여백만 확인

## 확인 항목

- 상·하단 UI 안전 영역과 배경 대비
- 중앙 자전거·작업대·주문 게시판의 식별성
- 따뜻한 픽셀 감성이 과도하게 약해지지 않는지
- Garage 3단계 성장 표현과 소품 추가 여유

## 현재 관찰

세 방안 중 모바일 UI 수용성과 중앙 자전거 가독성이 가장 좋습니다. 현재 MVP의 우선 후보지만, 실제 주문 카드와 PLAY 버튼을 올린 비교가 끝날 때까지 조건부 후보로만 둡니다.

## 에셋 기록

2026-08-14 이미지 생성 모델로 제작한 독자적 콘셉트 시안입니다. 특정 게임의 에셋·캐릭터·UI와 실제 자전거 브랜드를 사용하지 않았으며, 최종 출시 에셋이 아닌 Lab 비교용 임시 자료입니다.

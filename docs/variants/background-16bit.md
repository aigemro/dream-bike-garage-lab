# Prototype A: 정통 16비트 픽셀 공방

## 가설

낮은 색상 수와 굵은 실루엣은 자전거 작업실을 빠르게 읽게 하고, 따뜻한 복고 감성을 가장 강하게 전달할 수 있습니다.

## 공통 조건

- 390×810 세로 모바일 화면
- 좌측 작업대, 중앙 정비 스탠드, 우측 주문 게시판과 출입문
- 실제 브랜드·로고 미사용
- UI를 배경에 합성하지 않고 상·하단 오버레이 여백만 확인

## 확인 항목

- 중앙 자전거와 주요 행동 영역의 식별성
- 어두운 목재 배경 위 UI 대비
- 반복 노출 시 시각 피로
- Garage 3단계 성장 시 추가 에셋 제작량

## 현재 관찰

픽셀 정체성과 공방 분위기는 가장 강하지만, 소품과 어두운 명암이 모바일 UI와 경쟁할 가능성이 있습니다. 실제 UI 오버레이 검증 전에는 채택하지 않습니다.

## 에셋 기록

2026-08-14 이미지 생성 모델로 제작한 독자적 콘셉트 시안입니다. 특정 게임의 에셋·캐릭터·UI와 실제 자전거 브랜드를 사용하지 않았으며, 최종 출시 에셋이 아닌 Lab 비교용 임시 자료입니다.

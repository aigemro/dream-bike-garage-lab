# A안 · 따뜻한 픽셀 급여 봉투

관련 이슈: #179 납품·보상 정산 화면 디자인 트랙 · 상위 검증: #113

## 목적

주문 완료가 게임 화면 안 인라인 메시지로 끝나지 않도록, 납품 → 급여 수령 → 성장 게이지 → 다음 주문 예고를 하나의 정산 화면으로 잇습니다. A안은 고객이 건네는 급여 봉투 개봉을 중심에 둔 성취감 우선 구성입니다.

## 화면 구성 (390×810 · 홈 A안 팔레트)

1. 납품 완료 배너: DELIVERY DONE + 주문명 (통학용 어반 로드)
2. 납품 장면: 완성 자전거(홈 공용 모델) + 고객 캐릭터(#133 공용) + 감사 말풍선
3. 급여 봉투: 흔들리는 봉투를 탭하면 덮개가 열리고 코인 조각이 정산 패널로 날아감
4. 정산 패널: 보유 코인 2,480 → 3,480 카운트업(+1,000), 드림 바이크 성장 게이지 진행
5. 다음 주문 카드: NEXT ORDER · 트레일 MTB · 부품 4종 · 예상 급여 1,400 + [다음 주문 시작]·[HOME]

## 검증 절차

1. 진입 3초 안에 "납품이 끝나고 보상을 받는 화면"임이 읽히는지 확인합니다.
2. 봉투 탭 → 코인 카운트업 → 성장 게이지 진행이 하나의 흐름으로 느껴지는지 확인합니다.
3. 급여의 사용처(드림 바이크 성장)가 게이지 문구로 전달되는지 확인합니다.
4. 다음 주문 예고가 재플레이 동기를 만드는지 B/C안과 비교합니다.

## 규칙 경계

- 급여 1,000·게이지 진행량은 표현 검증용 고정값입니다. 보상 규칙은 #19, 성장 비용 데이터는 #116에서 결정합니다.

## 한계와 후속

- B안(작업 일지 정산형)·C안(성장 우선형)과 동일 데이터로 비교 후 채택 판단합니다.
- 게임 화면(#166) 주문 완료 시점에서 이 화면으로 실제 전환하는 연결은 채택 후 통합 트랙에서 다룹니다.

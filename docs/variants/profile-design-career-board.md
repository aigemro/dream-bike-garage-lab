# Prototype B: 따뜻한 픽셀 커리어 승진 보드

## 트랙 역할

이 방안은 승진 조건 수치를 다시 결정하지 않습니다. `META PROGRESSION > 직급·커리어 성장`(#107)의 직급 사다리 데이터를 홈 A안의 시각 언어로 화면화해, '직급(성장 경로)' 중심 프로필이 장기 목표를 얼마나 선명하게 만드는지 검증합니다. 정보 구조 검토는 `docs/PROFILE_SCREEN_DESIGN_REVIEW.md`를 따릅니다.

## 디자인 방향

- 견습 알바 → 샵 오너 6단계 직급 사다리를 세로 보드로 펼치고, 위로 올라가는 시선 축을 만듭니다.
- 완료(녹색)·현재(금색 강조)·잠금(어두운 종이)을 색과 태그로 함께 구분합니다.
- 상단에 다음 승진 조건(Lv.15 도달 + 납품 40건)의 이중 진행 바를 고정합니다.
- 각 단계를 누르면 해금 기능 안내를 보여줘 상위 직급의 기대감을 만듭니다.
- 하단 한 줄로 작업 통계가 승진 조건에 반영됨을 알려 통계와 직급을 연결합니다.

## 공통 조건

- 390×810 세로, 홈 A안과 동일 팔레트
- 동일 프로필 데이터: 정비사 두리 Lv.12, 견습 정비사(2/6단계), 납품 34/40, 통계 6종
- ← HOME으로 홈 A안 축약 프리뷰(프로필 탭 강조)와 전환하며 진입 흐름을 확인

## 인터랙션

직급 단계 탭 → 해당 직급의 해금 기능 안내 토스트. 승진 판정·조건 변경은 이 트랙에서 다루지 않습니다(규칙 비교는 #107 담당).

## 평가 기준

- 진입 3초 안에 '승진 경로 화면'임이 읽히는가
- 완료·현재·잠금 단계가 색·태그로 구분되는가
- 다음 승진 조건 진행 바가 남은 행동량을 체감시키는가
- 단계별 해금 안내가 상위 직급 기대감을 만드는가
- 6단계 사다리가 390 폭에서 답답하지 않은가

## 함께 비교하는 방안

- A안: 따뜻한 픽셀 정비사 사원증 (정체성 중심)
- C안: 따뜻한 픽셀 작업 기록 대시보드 (통계·그래프 중심)

세 방안은 같은 프로필 데이터와 홈 A안 진입 흐름을 사용하며, 화면의 주인공만 바꿔 비교합니다.

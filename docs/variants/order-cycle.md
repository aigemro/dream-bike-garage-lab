# A안 · 순환 주문 세트

## 검증 목적

초기 3종 주문이 머지·조립 규칙을 단계적으로 익히게 하고, 세 주문 이후 요구 레벨과 보상이 오른 변형 주문이 다음 플레이 목표를 만드는지 확인합니다.

## 1차 구현

- 어반 로드 → 트레일 MTB → 그래블 순서로 한 번에 주문 1건 제공
- 완료할 때마다 코인 누적과 다음 주문 미리보기 갱신
- 초기 3종 이후 같은 모델의 요구 레벨·보상 상승
- 완료 주문 수, 현재 회차, 다음 반복 목표 표시

## 비교 예정

- B안: 플레이 결과에 따라 다음 주문이 갈리는 조건부 분기
- C안: 난이도와 보상이 다른 주문 중 하나를 선택

## 관찰 항목

- 현재 목표와 다음 목표를 바로 이해하는가
- 세 번째 주문에서 난이도 상승을 느끼는가
- 초기 3종 이후 변형 주문을 시작하고 싶은가

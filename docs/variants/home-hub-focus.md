# 홈 허브 강조형 메인 홈

## 구현 방식
이벤트·Tour·랭킹을 상단의 명확한 허브 카드로 배치하고, 주문 정보는 압축 카드로 제공합니다. 장기 콘텐츠의 접근성을 높이면서 중앙 머지 보드는 계속 화면 안에서 플레이할 수 있도록 유지합니다.

## 확인할 점
- 부가 기능의 발견성과 재방문 동기가 높아지는지 확인합니다.
- 상단 허브 정보가 주문 목표와 머지 플레이 집중을 방해하지 않는지 관찰합니다.
- 여러 진입 버튼이 모바일 화면을 복잡하게 만들지 않는지 확인합니다.

## 비교 조건
A안·B안과 같은 주문, 재화, 스태미너, 보드 데이터와 메뉴 기능을 사용하고 정보 배치 우선순위만 비교합니다.

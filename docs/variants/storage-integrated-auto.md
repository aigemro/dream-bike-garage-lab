# C안 · 통합 상태 자동 저장·복구

관련 이슈: #5 앱 라이프사이클 및 상태 복구 검증 · 상위 검증: #113 출시 MVP 통합 검증

## 목적

A안 localStorage·B안 IndexedDB 비교(#3)에서 정리한 저장 계약(schemaVersion·revision·savedAt·복원 전 검증)을 출시 MVP의 통합 상태에 적용하고, 저장 버튼 없이도 라이프사이클 이벤트에서 자동 저장되는지 검증합니다.

## 저장 계약 (통합 상태 v1)

MVP_READINESS_PLAN의 로컬 저장 범위를 하나의 저장 데이터로 묶습니다.

- 보드: 부품 목록 (종류·레벨, 최대 12개)
- 현재 주문: 주문 번호와 부품별 장착 여부
- 코인
- 드림 바이크 성장 단계 (1~3)
- 튜토리얼 완료 여부
- 메타: schemaVersion, revision, savedAt, saveReason (수동 / 백그라운드 / 페이지 이탈)

## 자동 저장 시점

- `visibilitychange` → hidden: 탭 전환·창 최소화·모바일 홈 이동 시 저장
- `pagehide`: 새로고침·탭 닫기·다른 페이지 이동 시 저장
- 수동 저장 버튼: 비교 기준용

## 검증 절차

1. 택배 개봉 → 머지 → 장착 → 납품 → 성장으로 통합 상태를 변경합니다.
2. 수동 저장 없이 새로고침해 마지막 자동 저장 시점으로 복원되는지 확인합니다.
3. 다른 탭으로 전환한 뒤 돌아와 라이프사이클 이벤트 로그에 자동 저장이 기록되는지 확인합니다.
4. 저장 삭제 후 첫 실행 상태로 시작하는지 확인합니다.
5. 손상 데이터(스키마 불일치)는 진행에 적용하지 않고 새 진행 + 오류 안내로 처리하는지 확인합니다.

# Prototype B: 자전거 우선형

## 핵심 가설
- 주문 자전거를 상단에 크게 보여주면 부품이 완성되는 과정과 조립 성취감이 더 잘 전달된다.
- 주문 정보와 부품 제작을 하단에 배치하면 자전거 이미지와 보드의 겹침을 피할 수 있다.

## 동일 비교 조건
- A안과 같은 주문, 부품 목표, 머지 규칙, 납품 보상을 사용한다.
- 완성된 부품은 상단 자전거에 색상으로 즉시 반영한다.

## 확인할 점
- 자전거가 화면의 핵심 목표로 인식되는가
- 하단 주문 정보와 부품 제작 영역의 크기가 충분한가
- 조립 상태 변화가 다음 부품 제작 동기로 이어지는가

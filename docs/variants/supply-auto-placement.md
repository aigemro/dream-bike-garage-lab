# 배치 미리보기·자동 배치 토글형 부품 수급

관련 이슈: [#196 부품 수급 D안](https://github.com/aigemro/dream-bike-garage-lab/issues/196) · 상위 트랙: [#70 Parts Supply](https://github.com/aigemro/dream-bike-garage-lab/issues/70)

## 질문

택배 상자 개봉형의 기대감은 유지하면서, 배송 완료 뒤 반복되는 추가 클릭과 수동 배치 오류를 줄일 수 있는가?

## 가설

수동 배치에는 실제 부품 모양의 배치 미리보기를 제공하고, 반복 플레이에는 선택형 자동 배치를 제공하면 초반 학습과 반복 템포를 함께 지킬 수 있습니다.

## 비교 대상

- B안 택배 상자 개봉형: 배송 완료 후 상자를 눌러 직접 배치
- D안 자동 배치 OFF: B안 흐름 + 배치 가능/불가능·머지 미리보기
- D안 자동 배치 ON: 배송 완료 후 첫 번째 배치 가능한 위치로 즉시 투입

세 조건은 390×810 화면, 6×7 보드, 같은 주문·배송 시간·부품 모양을 사용합니다.

## 핵심 규칙

- 택배 선반의 체크박스로 자동 배치를 켜거나 끕니다.
- OFF에서는 상자를 개봉한 뒤 포인터가 있는 보드 칸에 반투명 부품 모양을 표시합니다.
- 기존 부품 이동과 같은 레벨 머지에도 놓기 전 미리보기를 표시합니다.
- ON에서는 배송 완료 시 위에서 아래, 왼쪽에서 오른쪽 순서로 첫 배치 가능 위치를 찾습니다.
- 기본 방향으로 들어가지 않으면 90도 단위 회전도 확인합니다.
- 공간이 없으면 택배를 `도착` 상태로 보존하고 수동 개봉 안내를 표시합니다.
- 자동 정리·자동 머지·자동 주문은 수행하지 않습니다.

## 평가 기준

- [ ] 배송 완료 후 추가 클릭 수가 줄어드는가?
- [ ] 수동 배치 전에 부품 크기·방향·겹침 여부를 이해할 수 있는가?
- [ ] 자동 배치가 보드 공간 판단을 지나치게 대신하지 않는가?
- [ ] 보드가 가득 찼을 때 부품 유실 없이 복구 방법을 이해할 수 있는가?
- [ ] 체크박스와 배송 카드가 390×810에서 겹치지 않는가?

## 실행 방법

1. 자동 배치 OFF에서 택배를 주문하고 도착 후 상자를 개봉합니다.
2. 보드 칸 위 미리보기의 가능·불가능 색과 머지 상태를 확인한 뒤 배치합니다.
3. 자동 배치를 ON으로 바꾸고 다른 택배를 주문합니다.
4. 배송 시간이 끝난 뒤 추가 클릭 없이 보드에 들어가는지 확인합니다.
5. 보드를 채운 상태에서 도착 택배가 보존되는지 확인합니다.

# Prototype A: 따뜻한 생활형 픽셀 Garage

## 트랙 역할

이 방안은 게임 구조를 다시 결정하지 않습니다. `GAME CORE > 메인 홈·플레이 화면 > E안`에서 합의한 Garage 홈 구조를 고정하고, 실제 플레이어가 매일 보게 될 홈 화면의 시각 언어를 검증합니다.

## 디자인 방향

- 따뜻한 목재 공방과 창밖의 녹색 풍경으로 생활감과 계절감을 만듭니다.
- 중앙 드림 바이크는 가장 큰 오브젝트로 두고, 하단 PLAY와 하나의 수직 시선 축을 형성합니다.
- 종이·나무 질감을 연상시키는 크림·갈색 UI와 굵은 외곽선을 사용해 작은 화면에서도 버튼 경계를 구분합니다.
- 공구 선반, 주문 게시판, 화분은 Garage의 이야기를 만들되 중앙 자전거보다 낮은 대비로 표현합니다.
- 특정 게임의 캐릭터·타일·아이콘·UI를 복제하지 않고 독자적인 자전거 공방 화면으로 구성합니다.

## 회의안 반영

1. 중앙: 나의 대표 자전거와 Garage 성장
2. 하단 중앙: 가장 큰 PLAY 버튼
3. 상단: 에너지·코인·현재 주문
4. 좌측: 이벤트·랭킹
5. 우측: Tour·조립·Status
6. 중앙 하단: 수집률과 다음 해금 목표

## 세밀화 (2차)

- 중앙 대표 자전거를 단순 프레임에서 공용 상세 모듈(`drawDreamBike`)로 교체했습니다. 스포크·허브·체인·크랭크·페달·안장·드롭바와 프레임 음영까지 표현하며, 픽셀 스냅으로 A안의 픽셀 감성을 유지합니다.
- 자전거 아래 정비 매트를 깔아 "작업 중인 공간"의 생활감을 더했습니다.
- 공구 벽을 페그보드(점 격자) + 실루엣이 다른 공구 4종(렌치·드라이버·망치·오일캔)으로 재작업했습니다.
- 주문 게시판 메모에 압정과 메모 라인을 추가하고 가운데 메모를 살짝 기울여 손맛을 냈습니다.
- 창밖에 해·구름·원경 나무 줄기, 창턱 화분을 더하고 벽에 낮은 대비의 판재 결을 깔았습니다.
- 바닥에 기대 놓은 타이어와 빨간 공구 상자를 배치하되, 상단 주문·좌우 메뉴·하단 PLAY의 가독성을 방해하지 않는 위치로 제한했습니다.
- 상단 주문 카드의 미니 자전거도 공용 미니 모듈(`drawDreamBikeMini`)로 교체해 대표 자전거와 실루엣을 통일했습니다.

## 세밀화 (3차) — 픽셀 스프라이트 자전거

- 중앙 드림 바이크를 선(line) 드로잉에서 새 공용 픽셀 스프라이트 모듈(`bike-pixel-sprite`)로 교체했습니다. 캐릭터 A안과 같은 픽셀 그리드 문법(굵은 잉크 외곽선 + 튜브 상단 하이라이트·하단 음영 2톤)으로 그려 화면 전체의 픽셀 밀도를 통일합니다.
- 실제 로드바이크 지오메트리(드롭바·바 테이프, 얇은 타이어와 크림 림, BB 드롭, 체인·크랭크·페달, 다운튜브 물통)를 64×40 픽셀 그리드에 래스터라이즈해 "진짜 자전거"로 읽히게 했습니다.
- 상단 주문 카드의 미니 자전거는 '통학용 어반 바이크' 주문에 맞춰 시티 자전거 실루엣(플랫바·펜더·앞바구니)으로 교체해, 주문마다 다른 자전거가 온다는 인상을 만듭니다.

## 인터랙션

PLAY를 누르면 축약된 주문·머지 화면으로 이동하며, HOME으로 돌아오면 플레이 결과가 Garage에 축적될 것이라는 흐름을 확인할 수 있습니다. 보조 메뉴는 현재 정보 계층만 검증하는 피드백 버튼입니다.

## 평가 기준

- 3초 안에 대표 자전거와 PLAY를 찾는가
- 배경 소품이 상단 주문과 좌우 메뉴의 가독성을 방해하지 않는가
- Garage가 단순 메뉴가 아니라 성장하고 소유하는 공간으로 느껴지는가
- 390×810 세로 화면에서 터치 영역과 텍스트가 읽히는가
- 반복 노출 시 색상과 소품 밀도가 피로하지 않은가

## 함께 비교하는 방안

- B안: 블루아워 정비소 Garage (몰입형 조명·정비 스탠드·상세 자전거 모델)
- C안: 레트로 아케이드 픽셀 Garage (픽셀 격자·제한 팔레트·도트 HUD)
- D안: 모던 캐주얼 모바일 Garage (밝은 그라데이션·글로시 라운드 카드 UI)

네 방안은 같은 회의안 정보 구조와 동일한 주문·수집 데이터를 사용하며, 시각 언어만 바꿔 비교합니다.

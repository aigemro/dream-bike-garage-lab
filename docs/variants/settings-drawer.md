# A안 · 따뜻한 픽셀 공방 관리 서랍

관련 이슈: #181 설정 화면 디자인 트랙 · QA 기준: #117

## 목적

출시 QA 최소 설정 요구(사운드 제어·튜토리얼 재진입·데이터 초기화·버전 표기)를 공방 서랍장 메타포로 담아, 설정 화면도 같은 Garage 공간의 일부로 느껴지게 하는 몰입형 구성입니다.

## 화면 구성 (390×810 · 홈 A안 팔레트)

- 헤더: SETTINGS 배지 + ← HOME 복귀
- 서랍장 프레임 안에 3개 서랍:
  - 소리 서랍(SOUND): 배경음악·효과음·진동 — 나무 스위치 토글 (ON 초록·오른쪽 / OFF 갈색·왼쪽)
  - 도움말 서랍(HELP): 튜토리얼 다시 보기 ↺
  - 기록 서랍(DATA): 저장 데이터 초기화 ⚠ — 빨간 테두리·경고 배색으로 위험 구분
- 데이터 초기화 2단계 확인: 탭 → 경고 모달("되돌릴 수 없습니다") → [취소]/[초기화 실행]
- 하단: 버전 v0.1.0-lab · 문의 표기 (데모)

## 검증 절차

1. 토글 ON/OFF 상태가 색·위치·문구 세 가지로 동시에 읽히는지 확인합니다.
2. 초기화 버튼이 다른 항목과 위험도가 다르게 보이는지, 모달 없이 실행되지 않는지 확인합니다.
3. 서랍장 메타포가 조작을 방해하지 않는지 B(체크리스트)·C(모달)안과 비교합니다.

## 규칙 경계

- 토글·초기화는 화면 표현 검증용 데모 동작입니다. 실제 사운드 연결은 #128·#129, 저장 초기화 동작은 #5 저장 트랙과 결합해 구현합니다.
- 계정·로그인·결제 설정은 MVP 밖이며 #6 앱인토스 SDK 트랙이 담당합니다.

## 한계와 후속

- 홈 화면의 설정 진입점 위치(상단 기어 아이콘 등)는 홈 A안 갱신 시 함께 비교합니다.

# Prototype A: 부드러운 공방 조작 피드백

## 공통 기준

홈 화면 디자인 A안의 포근함을 해치지 않도록 짧은 감쇠와 낮은 음량의 절차 생성 효과음을 사용합니다. 외부 음원 없이 Web Audio로 탭·부품 생성·머지·장착·납품·보상 여섯 행동을 구분합니다.

## 효과음 문법

- 탭: 짧고 둥근 목재 톡
- 부품 생성: 낮은 상자음에서 한 단계 올라가는 팝
- 머지: 두 음이 상승하며 합쳐지는 느낌
- 장착: 낮고 짧은 두 번의 체결 클릭
- 납품: 맑은 벨 두 음
- 보상: 빠르게 상승하는 동전 세 음

## 체험 방법

여섯 타일을 반복해서 누르고 화면을 보지 않아도 행동을 구분할 수 있는지, 연속 입력에서 피로하지 않은지 확인합니다.

## 평가 기준

- 성공 행동 여섯 가지가 소리만으로 구분되는가
- 머지와 장착이 캐주얼함과 기계적 조립감의 균형을 이루는가
- 연속 입력에서 음량과 고음이 과도하지 않은가
- 사용자 입력 전 재생하지 않고 화면 이탈 시 오디오가 종료되는가

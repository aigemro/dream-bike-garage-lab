# Prototype B: 고밀도 32비트 생활형 픽셀

## 가설

풍부한 공구·부품·재질과 섬세한 조명은 Garage를 단순 메뉴가 아니라 애착을 갖는 생활 공간으로 느끼게 할 수 있습니다.

## 공통 조건

- 390×810 세로 모바일 화면
- 좌측 작업대, 중앙 정비 스탠드, 우측 주문 게시판과 출입문
- 실제 브랜드·로고 미사용
- UI를 배경에 합성하지 않고 상·하단 오버레이 여백만 확인

## 확인 항목

- 소품 밀도와 중앙 자전거 주목도의 균형
- 축소 시 작은 디테일이 뭉치는 문제
- 완성차 전시와 수집 공간 확장성
- 제작 비용과 WebView 텍스처 예산

## 현재 관찰

생활감과 공간의 풍부함은 가장 크지만, 화면 정보량과 에셋 제작 비용도 가장 높습니다. 컬렉션 로비에는 유리하나 플레이 UI와 함께 쓰려면 저밀도 영역 확보가 필요합니다.

## 에셋 기록

2026-08-14 이미지 생성 모델로 제작한 독자적 콘셉트 시안입니다. 특정 게임의 에셋·캐릭터·UI와 실제 자전거 브랜드를 사용하지 않았으며, 최종 출시 에셋이 아닌 Lab 비교용 임시 자료입니다.

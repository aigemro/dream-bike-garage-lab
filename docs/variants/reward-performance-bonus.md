# 성과 보너스·성장 선택

## 구현 방식
납품 성과(부품 등급, 초과 달성 등)에 따라 보너스가 달라지고, 모은 재화로 성장 방향(수급 속도, 보드 확장, 수집 보너스 등)을 직접 선택합니다.

## 확인할 점
- 변동 보상이 납품의 긴장감과 성취감을 높이는지 확인합니다.
- 성장 선택지가 의미 있는 고민을 만드는지, 복잡도만 늘리는지 관찰합니다.
- 성과 기준이 플레이어에게 명확하게 전달되는지 확인합니다.

## 비교 조건
같은 주문 구성·납품 횟수에서 A안(고정 급여·직선 성장)을 기준선으로 보상 체감·선택의 재미·이해도를 비교합니다.

# 통합안: 선택안 기능 수직 슬라이스

## 목적

개별 트랙에서 선택한 기능을 다시 비교하지 않고, 주문 한 건의 시작부터 납품·급여·다음 주문까지 상태가 끊기지 않는지 검증합니다. 이번 작업은 기능 통합만 다루며 디자인, 아트 스타일과 고품질 연출은 평가하지 않습니다.

## 연결한 기능

- 주문: 로드 → MTB → 그래블 3종 순환
- 부품 수급: 현재 주문에 필요한 카테고리를 선택하는 택배 상자
- 머지: 6×5 자유 보드에서 동일 종류·동일 레벨 2-to-1
- 조립: 목표 레벨 달성 시 해당 부품을 보드에서 소비하고 자동 장착
- 납품: 모든 요구 부품 장착 후 급여 지급
- 성장: 주문 완료마다 드림 바이크 Stage 증가
- 저장: 택배·보드·주문·코인·성장·장착 상태를 행동마다 localStorage에 저장

## 조작 순서

1. 주문 카드에서 필요한 부품과 레벨을 확인합니다.
2. 필요한 카테고리의 택배 버튼을 눌러 상자를 보드에 추가합니다.
3. 상자를 눌러 Lv.1 부품을 획득합니다.
4. 같은 종류와 레벨의 부품 두 개를 차례로 눌러 머지합니다.
5. 주문 목표 레벨에 도달한 부품은 자동으로 장착됩니다.
6. 모든 부품 장착 후 납품해 급여와 성장 단계를 반영합니다.
7. 다음 주문으로 같은 흐름을 반복합니다.

## 검증 항목

- 택배가 보드 부품으로 변환되는 상태가 명확한가
- 머지 결과가 주문 목표 판정과 자동 장착으로 정확히 이어지는가
- 장착된 부품이 중복 소비되지 않는가
- 납품 전후 코인·성장·다음 주문 상태가 정확한가
- 새로고침 후 보드와 진행 상태가 복구되는가
- 보드가 가득 찼을 때 진행 막힘 안내가 나오는가

## 이번 구현에서 제외

- 홈 화면과 화면 전환 디자인
- 픽셀 아트, 자전거 모델 고도화, 장착 애니메이션
- 효과음과 배경음악
- 최종 모바일 Safe Area와 앱인토스 SDK
- 서버 저장과 계정 동기화

# B안: 확인 후 순차 장착

## 가설

완성 부품을 장착 대기열에 모으고 사용자가 `다음 부품 장착`을 누르면, 한 번의 가벼운 확인 조작으로 조립 순간의 통제감과 성취감을 높일 수 있습니다.

## 규칙

- 완성된 부품은 장착 대기 상태로 전환합니다.
- 사용자가 장착 진행을 누를 때 대기열의 첫 부품을 작업대로 이동합니다.
- 한 번에 한 부품만 장착하고 결과를 확인할 시간을 제공합니다.
- 장착 전·후 실루엣과 최종 납품 준비 표시는 A안과 동일합니다.

## 확인 항목

- 확인 조작이 조립 과정의 주도감을 높이는가
- 자동안보다 과정이 명확하게 기억되는가
- 주문마다 반복할 때 불필요한 추가 조작으로 느껴지지 않는가

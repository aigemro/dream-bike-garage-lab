# 기술 실험 운영 가이드

> 기준일: 2026-07-31  
> 대상 저장소: `aigemro/dream-bike-garage-lab`

이 문서는 기술 실험을 동일한 방식으로 만들고 검토하기 위한 기준입니다. 게임 기획과 설계의 정답을 정하는 문서가 아니라, 구현 가능성과 기술 선택의 근거를 남기는 문서입니다.

## 1. 실험 시작 조건

다음 질문에 답할 수 있을 때 실험을 시작합니다.

- 어떤 기술적 문제를 확인하려는가?
- 메인 게임에서 왜 필요한가?
- 어떤 기기, 브라우저 또는 플랫폼에서 확인할 것인가?
- 무엇이 되면 성공으로 판단하는가?
- 실패하거나 보류해야 하는 조건은 무엇인가?

기획 규칙이 정해지지 않아 기술 성공 여부를 판단할 수 없다면 메인 저장소에서 기획·설계를 먼저 확정합니다.

## 2. 실험 문서 템플릿

각 실험은 코드와 함께 아래 내용을 README 또는 결과 문서로 기록합니다.

```markdown
# 실험 이름

## 목적
검증하려는 문제와 메인 게임에서 필요한 이유

## 가설
선택한 기술이나 구현 방식이 적절하다고 예상하는 이유

## 검증 환경
- 브라우저/앱:
- OS/기기:
- 화면 크기:
- 네트워크 조건:
- 관련 버전:

## 성공 조건
- [ ] 측정하거나 직접 확인할 수 있는 조건
- [ ] 오류 및 예외 상황의 조건

## 실행 방법
설치, 실행, 조작 및 재현 절차

## 결과
측정값, 화면, 발견한 제약과 알려진 문제

## 결론
채택 / 조건부 채택 / 보류 / 폐기

## 메인 반영
관련 메인 저장소 Issue 또는 반영하지 않는 이유
```

## 3. 실험 상태

| 상태 | 의미 |
|---|---|
| 준비 | 목적과 성공 조건을 작성하는 단계 |
| 진행 | 실행 가능한 코드 또는 측정을 만드는 단계 |
| 검토 | 성공 조건을 기준으로 결과를 확인하는 단계 |
| 완료 | 결론과 메인 반영 여부까지 기록한 상태 |
| 보류 | 선행 결정이나 외부 환경을 기다리는 상태 |
| 폐기 | 채택하지 않기로 결정하고 이유를 기록한 상태 |

## 4. 구현 원칙

- 실험은 다른 기능에 영향을 적게 주는 독립 화면으로 만듭니다.
- 카탈로그 메인에서 실험 화면으로 이동할 수 있게 등록합니다.
- 마우스와 모바일 터치를 함께 확인합니다.
- Phaser Scene은 입력과 렌더링을 담당하고, 게임 규칙은 가능한 한 순수 TypeScript로 분리합니다.
- 앱인토스 SDK 호출은 게임 규칙에 직접 넣지 않고 플랫폼 어댑터 뒤로 분리합니다.
- 실제 키, 토큰, 개인정보 및 운영 결제 정보는 저장소에 커밋하지 않습니다.
- 실험에 필요한 최소 범위만 구현하고 완성 게임 수준의 장식이나 밸런싱은 하지 않습니다.

## 5. 기본 검증 항목

모든 화면형 실험에서 가능한 범위만 확인합니다.

- 데스크톱 마우스와 모바일 터치 입력
- 작은 화면에서 잘림과 스크롤 발생 여부
- 화면 회전, 백그라운드 이동 및 복귀
- 새로고침 후 상태 처리
- 로딩 시간과 큰 에셋 또는 번들 경고
- 콘솔 오류와 처리되지 않은 예외
- GitHub Pages의 하위 경로에서 에셋 로딩
- WebView 환경의 Safe Area와 뒤로가기

## 6. 결론 판정

- **채택**: 성공 조건을 충족하며 메인 게임에 적용할 수 있음
- **조건부 채택**: 제약과 적용 조건을 명시하면 사용할 수 있음
- **보류**: 기획, SDK, 서버 또는 테스트 환경이 준비되지 않음
- **폐기**: 성공 조건을 충족하지 못하거나 비용 대비 이점이 없음

팀의 기술 방향에 영향을 주는 결론은 `docs/decisions/`에 ADR로 남깁니다.

## 7. 메인 저장소 반영

Lab에서 완료한 실험은 자동으로 메인 게임의 구현 기준이 되지 않습니다.

1. 실험 결과와 결론을 검토합니다.
2. 메인 저장소에 적용 범위가 분명한 Issue를 만듭니다.
3. 기획·설계 문서와 충돌 여부를 확인합니다.
4. 메인 저장소 구조와 코딩 규칙에 맞게 구현합니다.
5. 원본 실험과 메인 Issue/PR을 서로 링크합니다.

Lab에는 상세 실험 과정과 실패 기록을 유지하고, 메인 저장소에는 최종 선택과 실제 제품 구현에 필요한 내용만 남깁니다.
